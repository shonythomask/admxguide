Edge Wallet E-Tree Enabled

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

The Edge Wallet E-Tree feature in Microsoft Edge allows users to plant a E-Tree for their own. If you enable or don't configure this policy, users can use the Edge Wallet E-Tree feature. If you disable this policy, users can't use the Edge Wallet E-Tree feature.
