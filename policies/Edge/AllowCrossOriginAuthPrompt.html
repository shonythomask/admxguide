Allow cross-origin HTTP Authentication prompts

Category

Computer Configuration > Administrative Templates > Microsoft Edge > HTTP authentication

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Controls whether third-party images on a page can show an authentication prompt. Typically, this is disabled as a phishing defense. If you don't configure this policy, it's disabled and third-party images can't show an authentication prompt.
