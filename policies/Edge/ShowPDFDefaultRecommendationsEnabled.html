Allow notifications to set Microsoft Edge as default PDF reader

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Content settings

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

This policy setting lets you decide whether employees should receive recommendations to set Microsoft Edge as PDF handler. If you enable or don't configure this setting, employees receive recommendations from Microsoft Edge to set itself as the default PDF handler. If you disable this setting, employees will not receive any notifications from Microsoft Edge to set itself as the default PDF handler.
