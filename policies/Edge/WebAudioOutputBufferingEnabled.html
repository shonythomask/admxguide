Enable adaptive buffering for Web Audio

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

This policy determines whether the browser enables adaptive buffering for Web Audio. Adaptive buffering can reduce audio glitches but may increase latency to varying degrees. Enabled: The browser will always use adaptive buffering. Disabled or Not Set: The browser will automatically decide during the feature launch process whether to use adaptive buffering.
