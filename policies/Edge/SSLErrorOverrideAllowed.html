Allow users to proceed from the HTTPS warning page

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Microsoft Edge shows a warning page when users visit sites that have SSL errors. If you enable or don't configure (default) this policy, users can click through these warning pages. If you disable this policy, users are blocked from clicking through any warning page.
