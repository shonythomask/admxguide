Minimum TLS version enabled (obsolete)

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

OBSOLETE: This policy is obsolete and doesn't work after Microsoft Edge 97. This policy was removed in Microsoft Edge 98 and is ignored if configured. Sets the minimum supported version of TLS. If you set this policy to 'tls1.2', Microsoft Edge will show an error for TLS 1.0 and TLS 1.1 and the user will not be able to bypass the error. If you don't configure this policy, Microsoft Edge will still show an error for TLS 1.0 and TLS 1.1 but the user will be able to bypass it. Support for suppressing the TLS 1.0/1.1 warning was removed from Microsoft Edge starting in version 91. The 'tls1' and 'tls1.1' values are no longer supported. Policy options mapping: * TLSv1 (tls1) = TLS 1.0 * TLSv1.1 (tls1.1) = TLS 1.1 * TLSv1.2 (tls1.2) = TLS 1.2 Use the preceding information when configuring this policy. Example value: tls1
