Allow user-level native messaging hosts (installed without admin permissions)

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Native Messaging

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

If you set this policy to Enabled or leave it unset, Microsoft Edge can use native messaging hosts installed at the user level. If you set this policy to Disabled, Microsoft Edge can only use these hosts if they're installed at the system level.
