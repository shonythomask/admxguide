Allow users to bypass Enhanced Security Mode

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Microsoft Edge will let users bypass Enhanced Security Mode on a site via Settings page or PageInfo flyout. This policy lets you configure whether users can bypass Enhanced Security Mode. If you disable this policy, Microsoft Edge won't allow users to bypass Enhanced Security Mode. If you enable or don't configure this policy, Microsoft Edge will allow users to bypass Enhanced Security Mode. For detailed information about Enhanced Security Mode, see https://go.microsoft.com/fwlink/?linkid=2185895
