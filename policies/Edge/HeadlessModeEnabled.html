Control use of the Headless Mode

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

This policy setting lets you decide whether users can launch Microsoft Edge in headless mode. If you enable or don't configure this policy, Microsoft Edge allows use of the headless mode. If you disable this policy, Microsoft Edge denies use of the headless mode.
