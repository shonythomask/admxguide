ADMX Guide

Show Microsoft Rewards experiences

Category

Computer Configuration > Administrative Templates > Microsoft Edge - Default Settings (users can override)

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge\Recommended

Description

Show Microsoft Rewards experience and notifications. If you enable this policy: - Microsoft account users (excludes Azure AD accounts) in search, new tab page, and earn markets will see the Microsoft Rewards experience in their Microsoft Edge user profile. - The setting to enable Microsoft Rewards in Microsoft Edge settings will be enabled and toggled on. If you disable this policy: - Microsoft account users (excludes Azure AD accounts) in search, new tab page, and earn markets will not see the Microsoft Rewards experience in their Microsoft Edge user profile. - The setting to enable Microsoft Rewards in Microsoft Edge settings will be disabled and toggled off. If you don't configure this policy: - Microsoft account users (excludes Azure AD accounts) in search, new tab page, and earn markets will see the Microsoft Rewards experience in their Microsoft Edge user profile. - The setting to enable Microsoft Rewards in Microsoft Edge settings will be enabled and toggled on.
