List of origins that allow all HTTP authentication

Category

Computer Configuration > Administrative Templates > Microsoft Edge > HTTP authentication

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Set this policy to specify which origins allow all the HTTP authentication schemes Microsoft Edge supports regardless of the 'AuthSchemes' (Supported authentication schemes) policy. Format the origin pattern according to this format (https://support.google.com/chrome/a?p=url_blocklist_filter_format). Up to 1,000 exceptions can be defined in 'AllHttpAuthSchemesAllowedForOrigins' (List of origins that allow all HTTP authentication). Wildcards are allowed for the whole origin or parts of the origin. Parts include the scheme, host, or port. Example value: *.example.com
