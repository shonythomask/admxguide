Enable the Collections feature

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Lets you allow users to access the Collections feature, where they can collect, organize, share, and export content more efficiently and with Office integration. If you enable or don't configure this policy, users can access and use the Collections feature in Microsoft Edge. If you disable this policy, users can't access and use Collections in Microsoft Edge.
