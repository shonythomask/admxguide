ADMX Guide

Choose whether users can receive customized background images and text, suggestions, notifications, and tips for Microsoft services

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Content settings

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Choose whether users can receive customized background images and text, suggestions, notifications, and tips for Microsoft services. If you enable or don't configure this setting, spotlight experiences and recommendations are turned on. If you disable this setting, spotlight experiences and recommendations are turned off.
