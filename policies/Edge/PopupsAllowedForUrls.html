Allow pop-up windows on specific sites

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Content settings

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Define a list of sites, based on URL patterns, that can open pop-up windows. Wildcards (*) are allowed. If you don't configure this policy, the global default value from the 'DefaultPopupsSetting' (Default pop-up window setting) policy (if set) or the user's personal configuration is used for all sites. Example value: https://www.contoso.com [*.]contoso.edu
