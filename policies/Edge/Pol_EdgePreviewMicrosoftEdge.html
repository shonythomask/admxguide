Allow users in the Windows Insider Program to be enrolled in Edge Preview

Category

Computer Configuration > Administrative Templates > Microsoft Edge Update > Applications > Microsoft Edge

Scope

Machine

Registry Key

HKLM\Software\Policies\Microsoft\EdgeUpdate

Description

Lets you specify whether users in the Windows Insider Program are enrolled in Edge Preview via Microsoft Edge Update. - If you enable (1) this policy, users in the Windows Insider Program are enrolled in Edge Preview via Microsoft Edge Update. - If you disable (0) this policy, users in the Windows Insider Program cannot be enrolled in Edge Preview via Microsoft Edge Update. - If you don't configure this policy, users in the Windows Insider Program are enrolled in Edge Preview via Microsoft Edge Update by default.
