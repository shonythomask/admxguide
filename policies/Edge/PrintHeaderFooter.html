Print headers and footers

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Printing

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Force 'headers and footers' to be on or off in the printing dialog. If you don't configure this policy, users can decide whether to print headers and footers. If you disable this policy, users can't print headers and footers. If you enable this policy, users always print headers and footers.
