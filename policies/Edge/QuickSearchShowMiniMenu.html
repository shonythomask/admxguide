Enables Microsoft Edge mini menu

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Enables the Microsoft Edge mini menu on websites and PDFs. The mini menu appears when users select text and provides basic actions like Copy and smart actions such as Definitions. If you enable or don't configure this policy, selecting text on websites or PDFs will show the mini menu. If you disable this policy, the mini menu won't appear when users select text on websites or PDFs. Note: Starting in Microsoft Edge for Mac version 143, this policy is obsolete because the mini menu feature has been removed on Mac.
