Double Click feature in Microsoft Edge enabled (only available in China)

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

This policy lets you configure the double click feature in Microsoft Edge. Double Click lets users close a tab by double clicking the left mouse button. If you enable or don't configure this policy, you can use the double click feature to close a tab on Microsoft Edge to start using this feature. If you disable this policy, you can't use the double click feature in Microsoft Edge.
