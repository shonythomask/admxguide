ADMX Guide

Allow Pin to taskbar wizard

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Microsoft Edge uses the Pin to taskbar wizard to help users pin suggested sites to the taskbar. The Pin to taskbar wizard feature is enabled by default and accessible to the user through the Settings and more menu. If you enable this policy or don't configure it, users can call the Pin to taskbar wizard from the Settings and More menu. The wizard can also be called via a protocol launch. If you disable this policy, the Pin to taskbar wizard is disabled in the menu and cannot be called via a protocol launch. User settings to enable or disable the Pin to taskbar wizard aren't available.
