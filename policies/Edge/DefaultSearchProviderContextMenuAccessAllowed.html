ADMX Guide

Allow default search provider context menu search access

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Enables the use of a default search provider on the context menu. If you set this policy to disabled the search context menu item that relies on your default search provider and sidebar search will not be available. If this policy is set to enabled or not set, the context menu item for your default search provider and sidebar search will be available. The policy value is only applied when the 'DefaultSearchProviderEnabled' (Enable the default search provider) policy is enabled, and is not applicable otherwise.
