Default pop-up window setting

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Content settings

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Set whether websites can show pop-up windows. You can allow them on all websites ('AllowPopups') or block them on all sites ('BlockPopups'). If you don't configure this policy, pop-up windows are blocked by default, and users can change this setting. Policy options mapping: * AllowPopups (1) = Allow all sites to show pop-ups * BlockPopups (2) = Do not allow any site to show popups Use the preceding information when configuring this policy.
