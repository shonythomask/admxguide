ADMX Guide

Allow pages to use the built-in AI APIs.

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Use this policy to control whether websites can access the built-in AI APIs, including the LanguageModel API, Summarization API, Writer API, and Rewriter API. Enable this policy to allow pages to use the APIs. If you don’t configure this policy, the APIs are still allowed. Disable this policy to block access to the APIs. The APIs will return an error when used. For more information, see https://github.com/webmachinelearning/writing-assistance-apis/blob/main/README.md.
