Enable Work Search suggestions in the address bar

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Enables the display of relevant workplace suggestions in the address bar’s suggestion dropdown when users type a query in the address bar. If this policy is enabled or not configured, users can view internal work-related suggestions, such as bookmarks, files, and people results powered by Microsoft 365, in the Microsoft Edge address bar suggestion dropdown. To access these results, users must be signed into Microsoft Edge with their Entra ID account associated with that organization. If this policy is disabled, users will not see internal workplace results in the Microsoft Edge address bar suggestion dropdown.
