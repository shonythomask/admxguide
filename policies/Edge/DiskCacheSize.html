ADMX Guide

Set disk cache size, in bytes

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

This policy configures the disk cache size in Microsoft Edge. If you enable this policy, Microsoft Edge uses the specified cache size, regardless of whether the user has set the --disk-cache-size command-line flag. The value defined in this policy is treated as a suggestion to the caching system, not a strict limit. Values below a few megabytes are rounded up to a reasonable minimum. If you set the value to 0, the default cache size is used and users cannot override it. It is recommended not to configure a custom value, as Microsoft Edge automatically manages the cache size for optimal performance. Setting a small value can degrade performance and increase network usage. If you don’t configure this policy, the default size is used, but users can override it with the --disk-cache-size flag. Note: The specified value is treated as a hint to multiple cache subsystems. The total disk usage of all caches may be larger than (but within the same order of magnitude as) the configured value.
