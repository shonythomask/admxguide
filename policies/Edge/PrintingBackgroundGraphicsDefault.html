Default background graphics printing mode

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Printing

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Overrides the last used setting for printing background graphics. If you enable this setting, background graphics printing is enabled. If you disable this setting, background graphics printing is disabled. Policy options mapping: * enabled (enabled) = Enable background graphics printing mode by default * disabled (disabled) = Disable background graphics printing mode by default Use the preceding information when configuring this policy. Example value: enabled
