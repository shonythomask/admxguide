ADMX Guide

Enable specific spellcheck languages

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Enables different languages for spellcheck. Any language that you specify that isn't recognized is ignored. If you enable this policy, spellcheck is enabled for the languages specified, as well as any languages the user has enabled. If you don't configure or disable this policy, there's no change to the user's spellcheck preferences. If the 'SpellcheckEnabled' (Enable spellcheck) policy is disabled, this policy will have no effect.
