ADMX Guide

Restore PDF view

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Enables PDF View Recovery in Microsoft Edge. If you enable or don't configure this policy Microsoft Edge will recover the last state of PDF view and land users to the section where they ended reading in the last session. If you disable this policy Microsoft Edge will recover the last state of PDF view and land users at the start of the PDF file.
