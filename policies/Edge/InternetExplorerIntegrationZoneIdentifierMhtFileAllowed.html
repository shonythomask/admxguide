Automatically open downloaded MHT or MHTML files from the web in Internet Explorer mode

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

This policy controls whether MHT or MHTML files that are downloaded from the web are automatically opened in Internet Explorer mode. If you enable this policy, the MHT or MHTML files that are downloaded from the web can be opened in both Microsoft Edge and Internet Explorer mode to provide the best user experience. If you disable or don't configure this policy, MHT or MHTML files that are downloaded from the web won't automatically open in Internet Explorer mode. To learn more about Internet Explorer mode, see https://go.microsoft.com/fwlink/?linkid=2094210
