Microsoft Edge management service policy overrides platform policy.

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Manageability

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

If you enable this policy, the cloud-based Microsoft Edge management service policy takes precedence if it conflicts with platform policy. If you disable or don't configure this policy, platform policy takes precedence if it conflicts with the cloud-based Microsoft Edge management service policy. This mandatory policy affects machine scope cloud-based Microsoft Edge management policies. Machine policies apply to all edge browser instances regardless of the user who is logged in.
