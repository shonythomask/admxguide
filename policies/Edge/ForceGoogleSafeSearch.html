Enforce Google SafeSearch

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Forces queries in Google Web Search to be performed with SafeSearch set to active, and prevents users from changing this setting. If you enable this policy, SafeSearch in Google Search is always active. If you disable this policy or don't configure it, SafeSearch in Google Search isn't enforced.
