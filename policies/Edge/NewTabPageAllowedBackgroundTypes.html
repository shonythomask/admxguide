Configure the background types allowed for the new tab page layout

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Startup, home page and new tab page

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

You can configure which types of background image that are allowed on the new tab page layout in Microsoft Edge. If you don't configure this policy, all background image types on the new tab page are enabled. Policy options mapping: * DisableImageOfTheDay (1) = Disable daily background image type * DisableCustomImage (2) = Disable custom background image type * DisableAll (3) = Disable all background image types Use the preceding information when configuring this policy.
