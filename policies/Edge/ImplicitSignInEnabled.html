Enable implicit sign-in

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Identity and sign-in

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Configure this policy to allow/disallow implicit sign-in. If you have configured the 'BrowserSignin' (Browser sign-in settings) policy to 'Disable browser sign-in', this policy will not take any effect. If you enable or don't configure this setting, implicit sign-in will be enabled, Edge will attempt to sign the user into their profile based on what and how they sign in to their OS. If you disable this setting, implicit sign-in will be disabled.
