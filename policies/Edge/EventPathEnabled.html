Re-enable the Event.path API until Microsoft Edge version 115 (obsolete)

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

OBSOLETE: This policy is obsolete and doesn't work after Microsoft Edge 115. Starting in Microsoft Edge version 109, the non-standard API Event.path will be removed to improve web compatibility. This policy re-enables the API until version 115. If you enable this policy, the Event.path API will be available. If you disable this policy, the Event.path API will be unavailable. If this policy is not set, the Event.path API will be in the following default states: available before version 109, and unavailable in version 109 to version 114. This policy will be made obsolete after Microsoft Edge version 115.
