Enhanced Security Mode configuration for Intranet zone sites

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Microsoft Edge will apply Enhanced Security Mode on Intranet zone sites by default. This may lead to Intranet zone sites acting in an unexpected manner. If you enable this policy, Microsoft Edge won't apply Enhanced Security Mode on Intranet zone sites. If you disable or don't configure this policy, Microsoft Edge will apply Enhanced Security Mode on Intranet zone sites. For detailed information about Enhanced Security Mode, see https://go.microsoft.com/fwlink/?linkid=2185895
