Include non-standard port in Kerberos SPN

Category

Computer Configuration > Administrative Templates > Microsoft Edge > HTTP authentication

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Specifies whether the generated Kerberos SPN should include a non-standard port. If you enable this policy, and a user includes a non-standard port (a port other than 80 or 443) in a URL, that port is included in the generated Kerberos SPN. If you don't configure or disable this policy, the generated Kerberos SPN won't include a port in any case.
