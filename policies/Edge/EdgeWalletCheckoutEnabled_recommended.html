Enable Wallet Checkout feature

Category

Computer Configuration > Administrative Templates > Microsoft Edge - Default Settings (users can override)

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge\Recommended

Description

Enables Wallet Checkout feature in Microsoft Edge. If you enable or don't configure this policy, users can choose whether to use wallet checkout while shopping on Microsoft Edge. If you disable this policy, users can't use wallet checkout while shopping on Microsoft Edge.
