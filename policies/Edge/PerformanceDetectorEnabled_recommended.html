ADMX Guide

Performance Detector Enabled

Category

Computer Configuration > Administrative Templates > Microsoft Edge - Default Settings (users can override) > Performance

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge\Recommended

Description

The performance detector detects tab performance issues and recommends actions to fix the performance issues. If you enable or don't configure this policy, performance detector is turned on. If you disable this policy, performance detector is turned off. The user can configure its behavior in edge://settings/system. Learn more about performance detector: https://aka.ms/EdgePerformanceDetector
