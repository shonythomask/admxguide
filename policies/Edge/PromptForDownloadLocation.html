Ask where to save downloaded files

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Set whether to ask where to save a file before downloading it. If you enable this policy, the user is asked where to save each file before downloading; if you don't configure it, files are saved automatically to the default location, without asking the user. If you don't configure this policy, the user will be able to change this setting.
