ADMX Guide

In-app support Enabled

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Microsoft Edge uses the in-app support feature (enabled by default) to allow users to contact our support agents directly from the browser. Also, by default, users can't disable (turn off) the in-app support feature. If you enable this policy or don't configure it, users can invoke in-app support. If you disable this policy, users can't invoke in-app support.
