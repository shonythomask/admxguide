Force Microsoft Defender SmartScreen checks on downloads from trusted sources

Category

Computer Configuration > Administrative Templates > Microsoft Edge > SmartScreen settings

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

This policy setting lets you configure whether Microsoft Defender SmartScreen checks download reputation from a trusted source. In Windows, the policy determines a trusted source by checking its Internet zone. If the source comes from the local system, intranet, or trusted sites zone, then the download is considered trusted and safe. If you enable or don't configure this setting, Microsoft Defender SmartScreen checks the download's reputation regardless of source. If you disable this setting, Microsoft Defender SmartScreen doesn't check the download's reputation when downloading from a trusted source. This policy is available only on Windows instances that are joined to a Microsoft Active Directory domain, Windows 10 Pro or Enterprise instances that enrolled for device management.
