Delay before running idle actions

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Idle Browser Actions

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Triggers an action when the computer is idle. If you set this policy, it specifies the length of time without user input (in minutes) before the browser runs actions configured via the IdleTimeoutActions policy. If you do not set this policy, no action will run. The minimum threshold is 1 minute. "User input" is defined by Operating System APIs, and includes things like moving the mouse or typing on the keyboard.
