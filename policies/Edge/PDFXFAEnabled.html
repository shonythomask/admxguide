ADMX Guide

XFA support in native PDF reader enabled

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Lets the Microsoft Edge browser enable XFA (XML Forms Architecture) support in the native PDF reader and allows users to open XFA PDF files in the browser. If you enable this policy, XFA support in the native PDF reader will be enabled. If you disable or don't configure this policy, Microsoft Edge will not enable XFA support in the native PDF reader.
