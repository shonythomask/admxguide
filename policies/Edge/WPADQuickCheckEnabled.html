ADMX Guide

Set WPAD optimization

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Allows you to turn off WPAD (Web Proxy Auto-Discovery) optimization in Microsoft Edge. If you disable this policy, WPAD optimization is disabled, which makes the browser wait longer for DNS-based WPAD servers. If you enable or don't configure the policy, WPAD optimization is enabled. Independent of whether or how this policy is enabled, the WPAD optimization setting cannot be changed by users.
