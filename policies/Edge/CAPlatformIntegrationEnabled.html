ADMX Guide

Use user-added TLS certificates from platform trust stores for server authentication

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Certificate management settings

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

If enabled (or unset), user-added TLS certificates from platform trust stores will be used in path-building for TLS server authentication. If disabled, user-added TLS certificates from platform trust stores will not be used in path-building for TLS server authentication.
