ADMX Guide

Specifies whether SharedArrayBuffers can be used in a non cross-origin-isolated context

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Specifies whether SharedArrayBuffers can be used in a non cross-origin-isolated context. A SharedArrayBuffer is a binary data buffer that can be used to create views on shared memory. SharedArrayBuffers have a memory access vulnerability in several popular CPUs. If you enable this policy, sites are allowed to use SharedArrayBuffers with no restrictions. If you disable or don't configure this policy, sites are allowed to use SharedArrayBuffers only when cross-origin isolated. Microsoft Edge will require cross-origin isolation when using SharedArrayBuffers from Microsoft Edge 91 onward for Web Compatibility reasons.
