Secure mode and Certificate-based Digital Signature validation in native PDF reader

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

The policy enables Digital Signature validation for PDF files in a secure environment, which shows the correct validation status of the signatures. If you enable this policy, PDF files with Certificate-based digital signatures are opened with an option to view and verify the validity of the signatures with high security. If you disable or don't configure this policy, the capability to view and verify the signature will not be available.
