Allow queries to a Browser Network Time service

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Prevents Microsoft Edge from occasionally sending queries to a browser network time service to retrieve an accurate timestamp. If you disable this policy, Microsoft Edge will stop sending queries to a browser network time service. If you enable this policy or don't configure it, Microsoft Edge will occasionally send queries to a browser network time service.
