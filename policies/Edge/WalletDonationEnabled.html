ADMX Guide

Wallet Donation Enabled

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

The Wallet Donation feature in Microsoft Edge allows users to view their donation summary, explore Nonprofit organizations (NPOs), donate to an NPO, manage their monthly donations, and view their donation history. If you enable or don't configure this policy, users can use the Wallet Donation feature. If you disable this policy, users can't use the Wallet Donation feature.
