ADMX Guide

Enables DALL-E themes generation

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

This policy lets you generate browser themes using DALL-E and apply them to Microsoft Edge. If you enable or don't configure this policy, the AI generated themes will be enabled. If you disable this policy, the AI generated themes will be disabled for your organization.
