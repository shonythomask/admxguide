ADMX Guide

Enable tab preview on hover

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

This policy controls whether Microsoft Edge displays a preview of the tab content when the user hovers over a tab. If you enable or don't configure this policy, Microsoft Edge shows a tab preview when the user hovers over a tab. If you disable this policy, tab previews will not be shown on hover.
