Allows system notifications

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Lets you use system notifications instead of Microsoft Edge's embedded Message Center on Windows and Linux. If set to True or not set, Microsoft Edge is allowed to use system notifications. If set to False, Microsoft Edge will not use system notifications. Microsoft Edge's embedded Message Center will be used as a fallback.
