Automatically grant sites permission to connect all serial ports

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Content settings

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Setting the policy allows you to list sites which are automatically granted permission to access all available serial ports. The URLs must be valid, or the policy is ignored. Only the origin (scheme, host, and port) of the URL is considered. This policy overrides 'DefaultSerialGuardSetting' (Control use of the Serial API), 'SerialAskForUrls' (Allow the Serial API on specific sites), 'SerialBlockedForUrls' (Block the Serial API on specific sites) and the user's preferences. Example value: https://www.example.com
