Enable upload files from mobile in Microsoft Edge desktop

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

This policy lets you configure the "Upload from mobile" feature in Microsoft Edge. Upload from mobile lets users select file from mobile devices to desktop when user upload file in a webpage in Microsoft Edge. If you enable or don't configure this policy, you can use the Upload from mobile feature in Microsoft Edge. If you disable this policy, you can't use the Upload from mobile feature in Microsoft Edge.
