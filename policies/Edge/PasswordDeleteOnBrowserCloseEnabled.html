ADMX Guide

Prevent passwords from being deleted if any Edge settings is enabled to delete browsing data when Microsoft Edge closes

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Password manager and protection

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

When this policy is enabled, the passwords saved with Edge Password Manager are exempted from deletion when the browser closes. This policy is only effective when the 'ClearBrowsingDataOnExit' (Clear browsing data when Microsoft Edge closes) policy is enabled. If you enable this policy, passwords won't be cleared when the browser closes. If you disable or don't configure this policy, the user's personal configuration is used.
