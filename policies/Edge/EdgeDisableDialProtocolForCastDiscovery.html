Disable DIAL protocol for cast device discovery

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Cast

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Enable this policy to disable the DIAL (Discovery And Launch) protocol for cast device discovery. (If EnableMediaRouter is disabled, this policy will have no effect). Enable this policy to disable DIAL protocol. By default, Cast device discovery will use DIAL protocol.
