Controls the display of the profile button label for the work or school profile

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Profile settings

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Controls whether the label for the work or school profile type is shown in the profile button. This policy does not apply when the OrganizationalBrandingOnWorkProfileUIEnabled policy is enabled. If you enable this policy, the label for the work or school profile type appears in the profile button. If you disable this policy or leave it not configured, the label is not shown.
