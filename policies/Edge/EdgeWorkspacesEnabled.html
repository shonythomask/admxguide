ADMX Guide

Enable Workspaces

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Edge Workspaces settings

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Microsoft Edge Workspaces helps improve productivity for users in your organization. If you enable or don't configure this policy, users will be able to access the Microsoft Edge Workspaces feature. If you disable this policy, users will not be able to access the Microsoft Edge Workspaces feature. To learn more about the feature, see https://go.microsoft.com/fwlink/?linkid=2209950
