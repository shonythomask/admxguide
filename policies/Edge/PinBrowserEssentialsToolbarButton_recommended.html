Pin browser essentials toolbar button

Category

Computer Configuration > Administrative Templates > Microsoft Edge - Default Settings (users can override) > Performance

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge\Recommended

Description

This policy lets you configure whether to pin the Browser essentials button on the toolbar. When the button is pinned, it will always appear on the toolbar. When the button isn't pinned, it will only appear when there's an alert. An example of this kind of alert is the performance detector alert that indicates the browser is using high CPU or memory. If you enable or don't configure this policy, the Browser essentials button will be pinned on the toolbar. If you disable this policy, the Browser essentials button won't be pinned on the toolbar. Learn more about browser essentials: https://go.microsoft.com/fwlink/?linkid=2240439
