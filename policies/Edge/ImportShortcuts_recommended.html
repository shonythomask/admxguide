Allow importing of shortcuts

Category

Computer Configuration > Administrative Templates > Microsoft Edge - Default Settings (users can override)

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge\Recommended

Description

Allows users to import Shortcuts from another browser into Microsoft Edge. If you disable this policy, Shortcuts aren't imported on first run. If you don't configure this policy, Shortcuts are imported on first run. You can also set this policy as a recommendation. This means that Microsoft Edge imports Shortcuts on first run. **Note**: This policy currently manages importing from Google Chrome (on Windows 7, 8, and 10 and on macOS).
