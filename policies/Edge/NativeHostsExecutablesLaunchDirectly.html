Force Windows executable Native Messaging hosts to launch directly

Category

Computer Configuration > Administrative Templates > Microsoft Edge

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

This policy controls whether native host executables launch directly on Windows. If you enable this policy, Microsoft Edge is forced to launch native messaging hosts implemented as executables directly. If you disable this policy, Microsoft Edge will launch hosts using cmd.exe as an intermediary process. If you don't configure this policy, Microsoft Edge will decide which approach to use based on a progressive rollout from the legacy behavior to the Launch Directly behavior, guided by ecosystem compatibility.
