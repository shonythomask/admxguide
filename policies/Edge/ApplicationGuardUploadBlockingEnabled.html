Prevents files from being uploaded while in Application Guard

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Application Guard settings

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Sets whether files can be uploaded while in Application Guard. If you enable this policy, users will not be able to upload files in Application Guard. If you disable or don't configure this policy, users will be able to upload files while in Application Guard.
