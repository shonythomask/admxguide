ADMX Guide

Enable the linked account feature (obsolete)

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Identity and sign-in

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

OBSOLETE: This policy is obsolete and doesn't work after Microsoft Edge 133. This policy is obsolete because Microsoft Edge no longer supports the linked account feature. Microsoft Edge guides a user to the account management page where they can link a Microsoft Account (MSA) to an Azure Active Directory (Azure AD) account. If you enable or don't configure this policy, linked account information will be shown on a flyout. When the Azure AD profile doesn't have a linked account it will show "Add account". If you disable this policy, linked accounts will be turned off and no extra information will be shown.
