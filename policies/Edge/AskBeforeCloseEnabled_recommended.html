Get user confirmation before closing a browser window with multiple tabs

Category

Computer Configuration > Administrative Templates > Microsoft Edge - Default Settings (users can override)

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge\Recommended

Description

This policy lets you configure whether users see a confirmation dialog before closing a browser window with multiple tabs. This dialog asks users to confirm that the browser window can be closed. If you enable this policy, users will be presented with a confirmation dialog when closing a browser window with multiple tabs. If you disable or don't configure this policy, a browser window with multiple tabs will close immediately without user confirmation.
