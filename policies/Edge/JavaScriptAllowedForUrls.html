Allow JavaScript on specific sites

Category

Computer Configuration > Administrative Templates > Microsoft Edge > Content settings

Scope

Both

Registry Key

HKLM\Software\Policies\Microsoft\Edge

Description

Define a list of sites, based on URL patterns, that are allowed to run JavaScript. If you don't configure this policy, 'DefaultJavaScriptSetting' (Default JavaScript setting) applies for all sites, if it's set. If not, the user's personal setting applies. For detailed information about valid url patterns, please see https://go.microsoft.com/fwlink/?linkid=2095322. Wildcards, *, are allowed. Example value: https://www.contoso.com [*.]contoso.edu
