Disable the new Sticky Notes experience

Category

User Configuration > Administrative Templates > Microsoft OneNote 2016 > OneNote Options > Other

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\onenote\options\other

Description

This policy controls the ability of users to access the new Sticky Notes experiences from OneNote. If you enable this policy setting, users will be unable to access the new Sticky Notes experiences from OneNote. If you disable this policy setting, users can access the new Sticky Notes experiences from OneNote. If you do not set this policy setting, users can access the new Sticky Notes experiences from OneNote. Note: This policy does not affect the classic Microsoft Sticky Notes app available on the Microsoft Store. Additionally, disabling or not setting this policy does not guarantee access to the new Sticky Notes experiences from OneNote.
