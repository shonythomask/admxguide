ADMX Guide

Cached Exchange low bandwidth threshold

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Account Settings > Exchange

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\rpc

Description

Specifies the bit rate threshold value. If the bit rate of the active network connection is below this value, Outlook identifies the network connection as a "slow" connection and operates accordingly (for example, downloading headers instead of full messages).
