Edits to total actual cost will be spread to the status date

Category

User Configuration > Administrative Templates > Microsoft Project 2016 > Project Options > Calculation > Calculation options for 'Project1'

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\ms project\options\calculation

Description

Distributes the changes to total actual cost evenly across the schedule to the status date (or to the current date if you have not specified a project status date). If you enable this setting, Project will distribute edits to actual cost evenly across a task up to the status date. If you disable or do not configure this setting, the user's default setting is used.
