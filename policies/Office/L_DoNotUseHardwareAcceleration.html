Do not use hardware graphics acceleration

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Miscellaneous

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\common\graphics

Description

This policy setting allows you to not use hardware graphics acceleration. If you enable this policy setting, hardware graphics acceleration will not be used. If you disable or do not configure this policy setting hardware graphics acceleration may be used.
