Don't show the option to transform a document to a Sway web page

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > General

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\options

Description

This policy setting controls whether the File menu option to transform a Word document to a Sway web page is shown to the user. By default, this option is shown to the user. If you enable this policy setting, the File menu option to transform a Word document to a Sway web page is hidden from the user. If you disable or don't configure this policy setting, the File menu option to transform a Word document to a Sway web page is shown to the user. Note: This policy setting only applies to subscription versions of Office, such as Microsoft 365 Apps for enterprise.
