Allow LinkedIn Resume Assistant feature

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > General

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\options

Description

This policy setting controls whether the LinkedIn Resume Assistant appears in Word. If you enable or do not configure this policy, users will be able to use the LinkedIn Resume Assistant. If you disable this policy setting, the LinkedIn Resume Assistant will not be available. Note: This policy setting only applies to subscription versions of Office, such as Microsoft 365 Apps for enterprise, and to subscription versions of Project and Visio.
