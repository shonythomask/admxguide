ADMX Guide

Enable MS Graph as Default Chart Tool in PowerPoint and Word

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Graph settings

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\common\charting

Description

Enables administrators to set the default chart creation tool to MS Graph instead of the default Excel Chart in PowerPoint and Word. Also blocks conversion of Graph charts to Office charts.
