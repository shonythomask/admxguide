Enable Exchange ActiveSync account creation in the Outlook account setup UI

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Account Settings > Exchange ActiveSync

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\setup

Description

This policy setting determines whether the Exchange ActiveSync button will be displayed in the account setup UI. If you enable this policy setting, the Exchange ActiveSync button will be displayed in Outlook account setup UI.
