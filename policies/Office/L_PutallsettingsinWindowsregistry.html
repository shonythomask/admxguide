Put all settings in Windows registry

Category

User Configuration > Administrative Templates > Microsoft Visio 2016 > Visio Options > Advanced > General Options

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\visio\application

Description

Adds all possible application settings into the Windows registry. By default, only certain settings are added (non-default settings and very few others, such as file paths, import and export filters, and last files) to keep the registry settings simple.
