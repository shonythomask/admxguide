ADMX Guide

Block processing of S/MIME encrypted messages by certain connected experiences

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Security > Trust Center

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\common\privacy

Description

This policy controls whether certain connected experiences that analyze your content can process email messages with S/MIME encryption. If you enable this policy setting, certain connected experiences that analyze your content can’t process email messages with S/MIME encryption. This means connected experiences such as the following won’t be available: - Spelling and grammar check (Editor) - Suggested replies - Automatically apply or recommend sensitivity labels - Microsoft Purview Data Loss Prevention policy tips For more information about which connected experiences are affected, see https://go.microsoft.com/fwlink/p/?linkid=2268773. If you disable or don’t configure this policy setting, all connected experiences that analyze your content can process email messages with S/MIME encryption. Note: This policy setting only applies to Microsoft 365 Apps for enterprise.
