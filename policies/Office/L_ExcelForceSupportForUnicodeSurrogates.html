Force support for Unicode surrogates in Excel 2021 and Excel 2024

Category

User Configuration > Administrative Templates > Microsoft Excel 2016 > Excel Options > Advanced

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\excel\options

Description

Warning: this setting alters how your app calculates LEN, MID, SEARCH, FIND and REPLACE and forces files to Compatibility Version 2. When these workbooks are shared, users may see different calculation results. This setting only applies to non-subscription Excel 2021 and Excel 2024. If you enable this policy setting, when any workbook is opened in non-subscription Excel 2021 or Excel 2024, it will automatically be set to Compatibility Version 2. This will cause LEN, MID, SEARCH, FIND and REPLACE functions to calculate differently in those workbooks. If you disable or do not configure this policy setting, the Compatibility Version will not be automatically set when a file is opened in any version of non-subscription Excel 2021 and Excel 2024 (this setting never affects other versions).
