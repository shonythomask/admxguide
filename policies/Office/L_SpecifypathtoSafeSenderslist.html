Specify path to Safe Senders list

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Outlook Options > Preferences > Junk E-mail

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\options\mail

Description

Specify a text file containing a list of e-mail addresses to append to or overwrite the Safe Senders list (depending on the policy "Overwrite or Append Junk Mail Import List").
