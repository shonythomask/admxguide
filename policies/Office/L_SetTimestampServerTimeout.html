ADMX Guide

Set timestamp server timeout

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Security Settings > Digital Signatures

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\common\signatures

Description

This policy setting allows you to configure the number of seconds Office 2016 applications wait for a response from the time stamping server before timing out. If timeout occurs, the Office 2016 application will not open the message or document. If you enable this policy setting, the number of seconds you specify will be the length of time Office 2016 will wait for the time stamping server to return a result. If you disable or do not configure this policy setting, the default of 5 seconds will be used.
