ADMX Guide

Hide lucky days when using Rokuyou (Japanese) calendar

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Outlook Options > Preferences > Calendar Options

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\options\calendar

Description

Checked: Does not display lucky days when using a Japanese Rokuyou calendar. | Unchecked: Displays lucky days when using a Japanese Rokuyou calendar.
