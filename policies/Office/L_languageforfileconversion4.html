Language for file conversion

Category

User Configuration > Administrative Templates > Microsoft Visio 2016 > Visio Options > Advanced > Save/Open

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\visio\application

Description

This policy setting specifies how Visio determines what language to use when converting to or from an earlier version of Visio. If you enable this policy setting, you may select from one of these options: - Let Visio decide language - Prompt for language - Use the following language: You must specify the numeric Microsoft Locale ID (LCID) for that language. If you disable or do not configure this policy setting, Visio decides what language to use.
