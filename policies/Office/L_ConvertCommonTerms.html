Convert common terms

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Review Tab > Chinese Conversion | Convert with Options

Scope

User

Registry Key

HKCU\software\policies\microsoft\shared tools\proofing tools\tcsc translator

Description

Checks/unchecks the corresponding UI option in the "Chinese Conversion" dialog, which found under Review tab | Convert with Options button. This may only be visible when Chinese is enabled as an editing language.
