ADMX Guide

Show menu on right mouse click

Category

User Configuration > Administrative Templates > Microsoft PowerPoint 2016 > PowerPoint Options > Advanced

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\powerpoint\options

Description

Checked: Checks the option ''Show menu on right mouse click''. | Unchecked: Unchecks the option ''Show menu on right mouse click''.
