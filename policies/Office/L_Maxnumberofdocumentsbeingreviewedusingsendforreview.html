ADMX Guide

Max number of documents being reviewed using 'send for review'

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Collaboration Settings

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\common\reviewcycle\docslots

Description

Sets the total number of documents that can be sent for review by a user before reusing registry entries from previous review cycles.
