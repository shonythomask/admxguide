Specify the number of restarts attempted for a running web extension

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Security > Trust Center

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\wef\outlook

Description

This policy setting allows you to specify the number of restarts Outlook attempts for a running web extension. If you enable this policy setting, you can specify the number of restarts Outlook attempts for a running web extension. If the web extension requires more than the specified number of restarts during an Outlook session, Outlook disables the web extension. If you disable or do not configure this policy setting, Outlook uses the default restart limit of 3 occurrences. The maximum restart limit is 10 occurrences, and the minimum restart limit is 1 occurrence.
