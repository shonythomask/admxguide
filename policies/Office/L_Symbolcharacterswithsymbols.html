Symbol characters (--) with symbols

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > Proofing > AutoFormat as you type > Replace as you type

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\options\assist

Description

Checks/unchecks the option ''Hyphens (--) with dash (-)''.
