Disable Microsoft Office shared drawing code for metafile rendering

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Miscellaneous

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\common\gelprefs

Description

Disables nearly all EMF's and WMF's will no longer be converted at runtime to be anti-aliased. Examples of EMF/WMF's that would remain "aliased" are: clipart, OLE object placeholders, any user inserted EMF/WMF image, etc. Any EMF/WMF containing text would be an exception to this and would be still getting anti-aliased.
