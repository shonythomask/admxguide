Disable Real Time Coauthoring for Word

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Collaboration Settings > Co-authoring

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\coauthoring

Description

This policy lets admins disable Real Time Coauthoring. They may want to do so if they have solutions that are not compatible with some elements of real time coauthoring, such as add-ins that would trigger too often due to Real Time Coauthoring causing the frequent saving of user content. If you enable this policy setting, it will prevent Real Time Coauthoring. If you disable or do not configure this policy setting, users will be able to experience Real Time Coauthoring feature.
