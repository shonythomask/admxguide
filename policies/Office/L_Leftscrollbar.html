ADMX Guide

Left scroll bar

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > Advanced

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\options

Description

Checks/unchecks the corresponding UI option. This option is only available if support for right-to-left languages is enabled through Microsoft Office Language Preferences. This setting also sets Right ruler (Print view only).
