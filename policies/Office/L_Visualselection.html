Cursor visual selection

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > Advanced

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\options

Description

Specifies if Block or Continuous selection shall be used. Block selection parodies the selection behavior within the Windows explorer when files in a folder. You draw a rectangle with the curson, and everything inside the rectangle is selected.
