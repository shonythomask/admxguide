Empty the Deleted Items folder when Outlook closes

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Outlook Options > Other

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\preferences

Description

By default, the Deleted Items folder is not emptied when users exit Outlook. By enabling this setting, you can change this behavior so that the Deleted Items folder is emptied when Outlook closes.
