ADMX Guide

Table compare colors

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > Track changes and compare

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\options

Description

This option determines the colors used for displaying the results of compared tables. Selecting ''none'' will track the changes, but they will not be colored in the resulting document (they will be listed in the reviewing pane).
