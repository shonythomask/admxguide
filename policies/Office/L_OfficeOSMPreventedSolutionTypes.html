Office solutions to exclude from Office Telemetry Agent reporting

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Telemetry Dashboard

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\osm\preventedsolutiontypes

Description

This policy setting allows you to prevent telemetry data for Office solutions from being reported to Office Telemetry Dashboard. If you enable this policy setting, Office Telemetry Agent does not upload telemetry data for the specified Office solutions to Office Telemetry Dashboard. If you disable or do not configure this policy setting, Office Telemetry Agent uploads telemetry data for all available solution types.
