Disallow custom cover sheet

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Services > Fax

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\common\services\fax

Description

Disables the custom fax cover sheet by displaying the message, "This option has been disabled by administrative policy" when the user clicks the Custom button in the Fax Service pane of the email message.
