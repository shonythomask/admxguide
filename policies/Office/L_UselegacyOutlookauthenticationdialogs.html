ADMX Guide

Use legacy Change Password authentication dialog boxes

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Account Settings > Exchange

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\rpc

Description

By default, Outlook displays the Windows authentication dialog box when users are prompted to change their passwords. By enabling this setting, you can change this behavior so that older-style Outlook dialog boxes that include the Change Password button are displayed.
