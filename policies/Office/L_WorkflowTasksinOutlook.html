Do not display "Open this task" button for workflow tasks

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Miscellaneous

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\common\workflow

Description

As part of E-mail notification of workflow tasks, users can edit a task by clicking the "Open this task" button to display the task dialog box for the workflow task. When this setting is enabled, the "Open this task" button is not displayed.
