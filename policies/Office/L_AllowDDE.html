Dynamic Data Exchange

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > Security > Trust Center

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\security

Description

This policy setting controls the ability to use Dynamic Data Exchange (DDE) in Word. By default, DDE isn’t allowed in Word. Allowing DDE isn’t recommended because of security concerns.   If you enable this policy setting, you can select either of the following options:   -Limit Dynamic Data Exchange -Allow Dynamic Data Exchange   If you choose “Limit Dynamic Data Exchange,” DDE requests made to an already running program are allowed.  But, DDE requests that require another executable program to be launched aren’t allowed.   If you disable or don’t configure this policy setting, DDE isn’t allowed.
