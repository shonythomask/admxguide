Turn off Research and Translation features in Visio

Category

User Configuration > Administrative Templates > Microsoft Visio 2016 > Visio Options > Proofing

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\visio\application

Description

This policy setting controls whether the Research and Translation features appear in Visio. If you enable this policy setting, users won’t see the Research and Translation features in Visio. If you disable or don't configure this policy setting, users will see the Research and Translation features in Visio. Note: This policy setting only applies to Visio LTSC 2021.
