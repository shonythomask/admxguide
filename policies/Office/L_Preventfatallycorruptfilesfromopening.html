ADMX Guide

Prompt to allow fatally corrupt files to open instead of blocking them

Category

User Configuration > Administrative Templates > Microsoft Publisher 2016 > Security

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\publisher

Description

When disabled, fatally corrupt files are prevented from opening. When enabled, the user is warned but may choose to open the file.By default, fatally corrupt files are prevented from opening.
