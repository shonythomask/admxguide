Category

User Configuration > Administrative Templates > Microsoft Visio 2016 > Visio Options > Advanced > Display

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\visio\document

Description

Specifies the unit of measure for indents, line spacing and other text measurements. The default unit for type size is points (1 point = 1/72 in.). You can enter type size in another unit of measure (for example, 1ft or 12 in) but you can't change the default.
