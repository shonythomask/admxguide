Turn off OneNote auto-linked note taking

Category

User Configuration > Administrative Templates > Microsoft OneNote 2016 > OneNote Options > Other

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\onenote\options\linkednotes

Description

This policy setting turns off the OneNote auto note taking feature which allows you to take notes on items such as webpages, Word documents, etc. OneNote will automatically record what pages or document you were viewing when you took this note. If you enable this policy setting, OneNote will not automatically link notes when the user tries to turn on this feature. If you disable or do not enable this policy, OneNote will automatically link notes when the user tries to turn on this feature.
