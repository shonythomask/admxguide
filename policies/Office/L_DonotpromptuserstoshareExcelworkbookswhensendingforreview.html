ADMX Guide

Do not prompt users to share Excel workbooks when sending for review

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Collaboration Settings

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\excel\options

Description

Checked: Do not prompt the user to share Excel workbooks when sending them for review. | Unchecked: Prompt the user to share Excel workbooks when sending them for review.
