Automatically insert a decimal point

Category

User Configuration > Administrative Templates > Microsoft Excel 2016 > Excel Options > Advanced

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\excel\options

Description

This policy setting allows you to configure the "Automatically insert a decimal point" option. If you enable this policy setting, the "Automatically insert a decimal point" option will be checked and the Places option is set to 2. If you disable or do not configure this policy setting, the "Automatically insert a decimal point" option will not be checked.
