Multiplier for foreground sync interval for the currently viewed section stored on SharePoint

Category

User Configuration > Administrative Templates > Microsoft OneNote 2016 > OneNote Options > Other

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\onenote\options\save

Description

This policy setting allows you to increase the interval between foreground polls of a SharePoint site for changes to the currently viewed section. If you enable this policy setting, OneNote will poll SharePoint less frequently for changes to the currently viewed section. Intervals are multiplied by the entered value, a positive integer value from 1 to 10. Larger intervals will slow section sync but reduce server load. If you disable or do not configure this policy setting, OneNote will sync the currently viewed section at the default rate (multiplier value of 1). Note: This policy setting only applies to volume licensed versions of Office 2016 that use Windows Installer (MSI), such as Office Professional Plus 2016 and Office Standard 2016.
