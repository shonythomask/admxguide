Allow PowerPoint to also automatically extend the display when presenting on a desktop

Category

User Configuration > Administrative Templates > Microsoft PowerPoint 2016 > PowerPoint Options > Advanced

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\powerpoint\options

Description

This policy setting specifies whether PowerPoint can also automatically extend the display when users present on a desktop computer. If you enable this policy setting, PowerPoint will automatically extend the display when users present on a desktop computer, if the "Automatically extend display when presenting on a laptop or tablet" checkbox on the UI under File | Options | Advanced | Display is checked. If you disable or do not configure this policy setting, PowerPoint does not automatically extend the display when users present on a desktop computer, even if the "Automatically extend display when presenting on a laptop or tablet" checkbox on the UI under File | Options | Advanced | Display is checked.
