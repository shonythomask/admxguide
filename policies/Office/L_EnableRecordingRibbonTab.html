Turn on recording ribbon tab

Category

User Configuration > Administrative Templates > Microsoft PowerPoint 2016 > Disable Items in User Interface > Predefined

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\powerpoint

Description

This policy setting allows you to control the initial recording ribbon tab in PowerPoint. By default, the tab is not visible. If you enable this policy setting, recording ribbon tab is visible. But, the user can choose to turn off the feature manually in the UI. If you disable or don’t configure this policy setting, recording ribbon tab is not visible. The user can choose to turn on the feature manually in the UI.
