ADMX Guide

Display enterprise themes

Category

User Configuration > Administrative Templates > Microsoft PowerPoint 2016 > PowerPoint Options > Advanced

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\powerpoint\options

Description

This policy allows you to display enterprise themes in the ribbon galleries. You can also name the category for the themes, and you can hide all the Office in-box and connected gallery themes.
