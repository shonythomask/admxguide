Enable Automation events

Category

User Configuration > Administrative Templates > Microsoft Visio 2016 > Visio Options > Advanced > General Options

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\visio\application

Description

Enables Visio events to be sent to Visio add-ons and VBA macros. If cleared, disables all Visio events. If you clear this option, some drawing types in Visio that rely on Automation events may not have full functionality.
