Disable Outlook features in the Feedback tab under the File menu in Outlook

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Outlook Options > Other

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\options\general

Description

This policy setting determines whether Outlook features will be displayed in the Feedback tab under the File menu in Outlook. If you enable this policy setting, then Outlook features will not be displayed in the Feedback tab under the File menu in Outlook.
