Graphics filter import

Category

Computer Configuration > Administrative Templates > Microsoft Office 2016 (Machine) > Security Settings

Scope

Machine

Registry Key

HKLM\software\policies\microsoft\office\common\security\allowlists\graphicsfilterimport

Description

This policy setting allows you to specify a list of graphic filters that 2016 Office applications load. If you enable this policy setting, you can specify a list of graphic filters that 2016 Office applications load. The graphic filters you specify must be assigned a string value FILTER.FLT (where FILTER.FLT is replaced with the name of a real filter), the value of which is XX.YY.ZZ.WW, where XX, YY, ZZ, and WW are each positive numbers less than 2^16, where the version in the registry is less than or equal to the version of the filter. For example: ''myfilter.flt''=''2006.1200.1000.1000'' If you disable or do not configure this policy setting, 2016 Office applications does not restrict any graphics filters from loading.
