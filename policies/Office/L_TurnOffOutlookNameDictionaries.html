Turn off Outlook name dictionaries update

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > IME (Japanese)

Scope

User

Registry Key

HKCU\software\policies\microsoft\imejp\16.0\wswordcomment\plugins\mapi

Description

This policy setting allows you to turn off updating for Outlook name dictionaries of Microsoft IME (Input Method Editor). This policy setting applies to Japanese Microsoft IME only. If you enable this policy setting, all Outlook name dictionaries are not updated. Outlook name dictionaries that were added before enabling this policy setting are used for conversion. If you disable or do not configure this policy setting, Outlook name dictionaries are generated, updated and used for conversion.
