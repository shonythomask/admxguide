ADMX Guide

Show highlighter marks

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > Display

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\options

Description

This policy setting controls highlighter marks. If you enable this policy setting, highlighter marks, both on screen and when printing, will be shown. If you disable or do not configure this policy setting, highlighter marks, both on screen and when printing, will be hidden.
