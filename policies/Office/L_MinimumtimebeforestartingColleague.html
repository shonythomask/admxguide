Minimum time before starting Colleague recommendation scan

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Server Settings > SharePoint Server

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\common\portal\colleagueimport

Description

The minimum idle time (in milliseconds) to wait before the Colleague Import Outlook add-in begins to scan the mailbox.
