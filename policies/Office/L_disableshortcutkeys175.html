Disable shortcut keys

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Disable Items in User Interface > Custom

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\disabledshortcutkeyslist

Description

This policy setting allows you to disable any shortcut key by using its virtual key code ID, including shortcut keys that are not in the predefined lists. If you enable this policy setting, you can enter a virtual key code ID number to disable a specific shortcut key. If you disable or do not configure this policy setting, all default shortcut keys are enabled for users.
