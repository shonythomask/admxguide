Configure fast shutdown behavior

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Miscellaneous > Miscellaneous

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\options\shutdown

Description

This policy setting controls Outlook's "fast shutdown" behavior. If you enable this policy setting, you may select one of these options: - MAPI provider does not support: Outlook should always use Fast Shutdown unless a MAPI provider explicitly does not support it. - All MAPI providers support: Outlook only uses Fast Shutdown if all MAPI providers do support it. - Never: Outlook never uses Fast Shutdown If you disable or do not configure this policy setting, the behavior will be the same as the "MAPI provider does not support" option.
