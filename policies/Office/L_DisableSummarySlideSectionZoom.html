Don’t allow Summary Zoom, Slide Zoom, and Section Zoom in a PowerPoint presentation

Category

User Configuration > Administrative Templates > Microsoft PowerPoint 2016 > PowerPoint Options > General

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\powerpoint

Description

This policy setting controls whether users can insert and playback a Summary Zoom, a Slide Zoom, or a Section Zoom in a PowerPoint presentation. By default, users can use these types of Zoom in a presentation. If you enable this policy setting, users can’t use these types of Zoom in a presentation. If you disable or don’t configure this policy setting, users can use these types of Zoom in a presentation.
