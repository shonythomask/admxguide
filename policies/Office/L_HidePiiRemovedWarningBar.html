Hide the PII Removed Warning Bar

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > Security

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\options

Description

This policy setting controls whether the yellow Warning Bar is displayed when opening a file in Word where personally identifiable information (PII) has been removed. If you enable this policy setting, the Warning Bar will not appear when users open a file in which PII was removed. If you disable this policy setting, the Warning Bar will appear when users open a file in which PII was removed. This is the default behavior. If you do not configure this policy setting, the Warning Bar will appear when users open a file in which PII was removed. This is the default behavior.
