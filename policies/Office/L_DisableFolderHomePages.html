Do not allow Home Page URL to be set in folder Properties

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Folder Home Pages for Outlook Special Folders

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\webview

Description

By default, users can set a URL to be used as the Home Page for a folder by entering the URL on the Home Page tab on the folder's Properties dialog box. By enabling this setting, you can disallow setting Folder Home Pages for all folders.
