Set parameters for CNG context

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > Security > Cryptography

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\security\crypto

Description

This policy setting allows you to specify the encryption parameters that should be used for the CNG context. If you enable this policy setting, the parameters specified will be passed to the CNG context. If you disable or do not configure this policy setting, the default CNG values will be used.
