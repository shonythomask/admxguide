Use a device-based license for Microsoft 365 Apps for enterprise

Category

Computer Configuration > Administrative Templates > Microsoft Office 2016 (Machine) > Licensing Settings

Scope

Machine

Registry Key

HKLM\software\policies\microsoft\office\16.0\common\licensing

Description

This policy setting controls whether Microsoft 365 Apps for enterprise uses a device-based license instead of a user-based license. Important: For eligibility requirements and configuration steps to use a device-based license with Microsoft 365 Apps for enterprise, see https://go.microsoft.com/fwlink/p/?linkid=2094216. If you enable this policy setting, Microsoft 365 Apps for enterprise will use a device-based license instead of a user-based license. If you disable or don’t configure this policy setting, Microsoft 365 Apps for enterprise will use a user-based license. Therefore, the user who signs in and activates Office must have an Office license.
