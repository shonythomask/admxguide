ADMX Guide

EAS Sync Frequency

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Account Settings > Exchange ActiveSync

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\eas

Description

This policy setting allows you to specify the number of minutes that Outlook automatically syncs the users' Exchange ActiveSync (EAS) accounts. If you enable this policy setting, you can specify the number of minutes. If you disable or do not configure this policy setting, Outlook automatically syncs the users’ EAS accounts every 59 minutes.
