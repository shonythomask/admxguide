Set the minimum operating system for verifying agile VBA signatures

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Security Settings > Trust Center

Scope

User

Registry Key

HKCU\software\policies\microsoft\vba\security

Description

This policy setting allows you to set the minimum operating system (OS) on which agile VBA signatures produced by Office can be verified. This ensures the hashing algorithm used to sign is compatible with the specified OS and later versions. If you enable this policy setting, Office uses the OS you specify as the minimum OS to verify agile VBA signatures. If you disable or do not configure this policy setting, Office uses Windows 7 as the minimum OS to verify agile VBA signatures. If you specify a minimum OS version that is higher than the highest OS supported by Office, Office uses the highest supported OS to verify agile VBA signatures.
