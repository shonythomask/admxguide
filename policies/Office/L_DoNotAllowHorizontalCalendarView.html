Do not allow horizontal calendar view

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Outlook Options > Preferences > Calendar Options > Schedule View

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\options\calendar

Description

This policy setting allows you to prevent horizontal calendar view. If you enable this policy setting, horizontal calendar view is not allowed. If you disable or do not configure this policy setting, horizontal calendar view is allowed.
