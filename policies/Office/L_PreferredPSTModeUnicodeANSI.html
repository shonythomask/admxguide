Preferred PST Mode (Unicode/ANSI)

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Miscellaneous > PST Settings

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook

Description

Specifies whether new PST files created by the user are to be in Unicode or ANSI format, and whether the user is allowed to choose that format.
