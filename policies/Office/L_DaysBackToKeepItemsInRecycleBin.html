Days back to keep items in recycle bin

Category

User Configuration > Administrative Templates > Microsoft OneNote 2016 > OneNote Options > Versions and Recyle Bin

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\onenote\options\versions

Description

This policy setting allows you to set the number of days before which all items added to the Recycle Bin before value will be deleted when the version history is pruned. With a 2016 format notebook, OneNote will automatically store previous versions of the pages in the notebook, and it will also store a recycle bin for all of the deleted pages and sections. If you enable this policy setting, you can set the number of days in the past to keep recycle bin items. If you do not configure this policy setting OneNote will use the default value of 60 days in the past.
