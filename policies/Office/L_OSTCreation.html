Do not allow an OST file to be created

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Account Settings > Exchange

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\ost

Description

Prevents offline folder use at startup. This is equivalent to clicking the Disable Offline Use button in the Offline Folder Settings dialog box.
