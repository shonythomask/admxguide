URL for S/MIME certificates

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Security > Cryptography

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\security

Description

This policy setting provides a URL at which Outlook users can obtain S/MIME certificates. If you enable this policy setting, you can enter a URL from which users can obtain S/MIME certificates. The URL can contain three variables, %1, %2, and %3, which will be replaced by the user's name, e-mail address, and language, respectively. When users click "Get a Digital ID", they will be directed to the supplied URL. If you disable or do not configure this policy setting, a URL for S/MIME certificates is not provided.
