Update linked data before printing

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > Display

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\options\vprsu

Description

This policy setting controls the "Update linked data before printing" setting found under File tab | Options | Display | Printing options. If you enable this policy setting, Word will update linked data in the document before the document is printed. One example of linked data in Word is an embedded Excel chart that is linked to an Excel spreadsheet. If you disable or do not configure this policy setting, Word will not update linked data in the document before the document is printed.
