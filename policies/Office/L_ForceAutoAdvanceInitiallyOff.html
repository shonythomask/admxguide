Turn off automatically advancing slides (Use Timings) initially

Category

User Configuration > Administrative Templates > Microsoft PowerPoint 2016 > Disable Items in User Interface > Predefined

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\powerpoint\options

Description

This policy settings allows you to set the initial state of automatically advancing slides (Use Timings). If you enable this policy, automatically advancing slides (Use Timings) will be set to off initially for all new and existing presentations. If you disable or do not configure this policy, automatically advancing slides (Use Timings) is set to on for new presentations, and for existing presentations to the state that was saved in the file. This is the default behavior.
