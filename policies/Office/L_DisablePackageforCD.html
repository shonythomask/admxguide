Disable Package For CD

Category

User Configuration > Administrative Templates > Microsoft PowerPoint 2016 > PowerPoint Options > Save

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\powerpoint\security

Description

Check to Disable Package for CD; Uncheck to Enable Package for CD. Shows or hides the File tab | Save & Send | Package Presentation for CD command. Package for CD allows the user to package and burn presentations onto CD for portable viewing even when PowerPoint is not installed.
