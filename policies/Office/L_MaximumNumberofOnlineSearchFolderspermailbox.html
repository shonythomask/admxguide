ADMX Guide

Maximum Number of Online Search Folders per mailbox

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Search Folders

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\options\general

Description

Specifies the maximum number of Search Folders that run on the Exchange server. The number of Search Folders running on the client computer is not affected.
