PST Null Data on Delete

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Miscellaneous > PST Settings

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\pst

Description

This policy setting allows you to force Outlook to fully nullify deleted data in users’ Personal Folder files (.pst) at the time that the data is deleted. If you enable this policy setting, data is immediately nullified in PST files when deleted. If you disable or do not configure this policy setting, data remains in PST files until it is purged or overwritten by the user.
