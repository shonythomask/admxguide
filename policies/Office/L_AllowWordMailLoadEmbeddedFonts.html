Allow embedded TrueType fonts to be sent in messages

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > Security > Trust Center

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\security

Description

This policy setting controls whether embedded TrueType fonts can be sent in messages. By default, embedded TrueType fonts aren't allowed in messages. Allowing embedded TrueType fonts Isn't recommended because of security concerns. If you enable this policy setting, embedded TrueType fonts can be sent in messages. If you disable or don’t configure this policy setting, embedded TrueType fonts can't be sent in messages.
