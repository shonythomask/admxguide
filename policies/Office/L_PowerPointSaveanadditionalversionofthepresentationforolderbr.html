ADMX Guide

PowerPoint: Save an additional version of the presentation for older browsers

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Web Archives

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\powerpoint\internet

Description

Checked: PowerPoint publishes Web Archive presentations that contain a version of the presentation that is compatible with older browsers. | Unchecked: PowerPoint publishes Web Archive presentations that contain only the version of the presentation that is compatible with later browsers.
