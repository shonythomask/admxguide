OneNote Spelling Options

Category

User Configuration > Administrative Templates > Microsoft OneNote 2016 > OneNote Options > Spelling

Scope

User

Registry Key

HKCU\software\policies\microsoft\shared tools\proofing tools\1.0\office

Description

These options change the "When correcting spelling in OneNote" options that appear in the File tab | Option | Proofing dialog box.
