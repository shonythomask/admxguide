Manage automatic setup of classic Outlook accounts in new Outlook

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Outlook Options > Other

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\preferences

Description

This policy setting allows you to manage whether classic Outlook automatically sets up user accounts and settings in new Outlook. If you enable this policy setting, automatic setup of user accounts and settings in new Outlook is allowed and cannot be changed by the user. If you disable this policy setting, automatic setup of user accounts and settings in new Outlook is not allowed and cannot be changed by the user. If you don't configure this policy setting, users can manage the setting themselves. Automatic setup is enabled by default.
