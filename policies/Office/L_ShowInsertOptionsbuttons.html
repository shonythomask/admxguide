ADMX Guide

Show Insert Options buttons

Category

User Configuration > Administrative Templates > Microsoft Excel 2016 > Excel Options > Advanced

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\excel\options\binaryoptions

Description

This policy setting sets the "Show Insert Options buttons" option found under File tab | Options | Advanced | Cut, copy, and paste options. If you enable or do not configure this policy setting, Excel will show the Insert Options button after inserting cells, rows, or columns that contain formatting. This is the default behavior. If you disable this policy setting, Excel will not display the Insert Options buttons on insert.
