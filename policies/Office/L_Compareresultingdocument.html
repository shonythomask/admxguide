ADMX Guide

Compare resulting document

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > Track changes and compare

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\options

Description

This option determines whether the results of a document compare or combine will appear in a new document or one of the source documents. This corresponds to the option in the Compare dialog box ( Review ribbon | Compare | more options).
