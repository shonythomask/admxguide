Change the limit for the number of MIME headers

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > MIME to MAPI Conversion

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\options\mail

Description

By default, the limit is 20000 for the number of MIME headers when an e-mail message is converted from MIME to MAPI. The number can be set to any positive integer. This helps prevent scenarios in which Outlook hangs while attempting conversion.
