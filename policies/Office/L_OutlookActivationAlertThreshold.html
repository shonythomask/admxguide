Specify activation disabling threshold for web extensions

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Security > Trust Center

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\wef\outlook

Description

This policy setting allows you to specify the threshold that Outlook refers to before disabling a web extension during activation. If you enable this policy setting, you can specify a threshold (in milliseconds) for the activation manager retry limit during an Outlook session. If the web extension requires more than the specified threshold for the number of occurrences specified by the activation manager retry limit during an Outlook session, Outlook disables the web extension. If you disable or do not configure this policy setting, Outlook uses the default activation alert threshold of 1000 milliseconds. The maximum activation alert threshold is 10000 milliseconds, and the minimum activation alert threshold is 100 milliseconds.
