Specify CNG hash algorithm

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > Security > Cryptography

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\security\crypto

Description

This policy setting allows you to specify the hash algorithm used. If you enable this policy setting, the hashing algorithm selected will be used by CNG. If you disable or do not configure this policy setting, the default CNG hash algorithm will be used.
