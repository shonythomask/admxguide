ADMX Guide

Stencils

Category

User Configuration > Administrative Templates > Microsoft Visio 2016 > Visio Options > Advanced > File Locations

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\visio\application

Description

Displays the additional location of stencils. When a location is added here, stencils in this location are listed on the Shapes submenu from the file menu.
