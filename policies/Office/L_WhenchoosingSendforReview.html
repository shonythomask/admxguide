ADMX Guide

When choosing 'Send for Review...'

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Collaboration Settings

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\common\general

Description

"Send link and attachment": When choosing Send for Review for a document on a server, send both a link and an attachment. | "Only send link": When choosing Send for Review for a document on a server, send only a link. | "Prompt user": When choosing Send for Review for a document on a server, prompt the user for what to send.
