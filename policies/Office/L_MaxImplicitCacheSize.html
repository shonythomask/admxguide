Set the max size of the Office Document Cache

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Miscellaneous

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\common\fileio

Description

This policy controls how large the user's Office Document Cache can be. It does not apply to explicitly cached files on "OneDrive for Business Client" and "OneDrive (consumer) Client".
