Permanently remove all deleted content from PST and OST files

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Miscellaneous > PST Settings

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\pst

Description

By default, a small percentage of deleted data is not overwritten in Outlook PST and OST files. By enabling this setting, all deleted data in PST and OST files is overwritten when users exit Outlook.
