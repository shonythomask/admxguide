Show more handles on hover

Category

User Configuration > Administrative Templates > Microsoft Visio 2016 > Visio Options > Advanced > Editing Options

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\visio\application

Description

This policy setting allows you to show more shape handles when hovering over a selected shape. If you enable this policy setting, more shape handles will be shown after a brief delay. If you disable or do not configure this policy setting, more shape handles will not be shown.
