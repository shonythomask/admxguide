Use Taiwan, Hong Kong SAR and Macao SAR character variants

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Review Tab > Chinese Conversion | Convert with Options

Scope

User

Registry Key

HKCU\software\policies\microsoft\shared tools\proofing tools\tcsc translator

Description

This policy setting allows you to configure the "Chinese Conversion" dialog, which is accessed by the "Convert with Options" button in the Review tab. This may only be visible when Chinese is enabled as an editing language. If you enable this policy setting, the option is selected. If you disable or do not configure this policy setting, the option is not selected.
