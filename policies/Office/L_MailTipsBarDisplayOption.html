MailTips bar display options

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Outlook Options > Preferences > E-mail Options

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\options\mail

Description

This policy setting controls MailTips bar display options. If the "Disable MailTips" policy is also enabled, this policy takes precedence. If you enable this policy setting, you can choose from three options for determining how the MailTips bar will display: - Display automatically when MailTips apply - Display at all times - Never Display MailTips If you disable or do not configure this policy setting, users can choose how the MailTips bar will display.
