ADMX Guide

Allow Web Archives to be saved in any HTML encoding

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Web Archives

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\common\internet

Description

Enabled: Allow the user to save Web Archives in any HTML encoding. Not enabled: Always use US-ASCII for Web Archives. This results in smaller files, but is not supported in Windows Internet Explorer 5.0 or earlier.
