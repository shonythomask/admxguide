Use an alternate method of anchoring content marks from CLP labels

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > General

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\options

Description

This policy setting switches Word to use a alternate method of anchoring content marks associated with CLP labels, which can improve layout for some content marks. If you enable this policy setting, Word will use the alternate content mark anchoring method. If you disable or don't configure this policy setting, Word will use the original content mark anchoring method. Note: This policy setting only applies to subscription versions of Office, such as Microsoft 365 Apps for enterprise.
