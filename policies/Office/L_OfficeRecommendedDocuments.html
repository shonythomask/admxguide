Show recommended files on the File tab or start page

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Miscellaneous

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\common\general

Description

This policy setting allows you to control whether users see a list of recommended files on the File tab or start page in Word, Excel, and PowerPoint, on devices running Windows. If you enable this policy setting, users will see a list of recommended files on the File tab or start page. If you disable this policy setting, users won't see a list of recommended files on the File tab or start page. If you don't configure this policy setting, users will see a list of recommended files on the File tab or start page. For more information, see https://go.microsoft.com/fwlink/p/?linkid=2146780. Note: This policy setting only applies to subscription versions of Office, such as Microsoft 365 Apps for enterprise.
