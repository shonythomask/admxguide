Keep the last AutoSaved versions of files for the next session

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > Save

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\options

Description

This policy setting determines whether Word keeps the last AutoSaved version of a file if a user closes a file without saving it. (Note: AutoSave applies only when AutoRecover is enabled.) If you enable or do not configure this policy setting, Word keeps the last AutoSaved version of the file and makes it available to the user the next time the file is opened if the user closes a file without saving it. If you disable this policy setting, Word does not keep the last AutoSaved version of the file if the user closes a file without saving it.
