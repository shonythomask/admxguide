ADMX Guide

Disable MRU list in font dropdown

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Miscellaneous

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\options

Description

This policy allows you to hide the list of recently used fonts found under Home tab | Font. If you enable this policy setting, the list of recently used fonts will not be shown. If you disable or do not configure this policy setting, the list of recently used fonts will be shown.
