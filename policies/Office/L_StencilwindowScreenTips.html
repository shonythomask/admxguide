Stencil window ScreenTips

Category

User Configuration > Administrative Templates > Microsoft Visio 2016 > Visio Options > Advanced > Display

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\visio\application

Description

Specifies whether ScreenTips (ScreenTips: Tips that appear when you pause the pointer over certain elements in the Visio program, including: masters on stencils, toolbar buttons, and the ruler) appear in Visio to help you identify shapes in the stencil window.
