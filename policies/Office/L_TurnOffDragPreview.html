ADMX Guide

Turn off drag preview

Category

User Configuration > Administrative Templates > Microsoft Publisher 2016 > Publisher Options > Advanced

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\publisher\preferences

Description

This policy setting allows you to determine whether Publisher shows a semi-transparent drag preview or a simple outline of the object when the object is dragged. If you enable this policy setting, only the outline of the object is shown while being dragged. This is the recommended setting for older machines because of the resource requirements of this feature. If you disable or do not configure this policy setting, a semi-transparent drag preview of the object is shown while being dragged.
