ADMX Guide

Publish interval

Category

User Configuration > Administrative Templates > Microsoft Outlook 2016 > Outlook Options > Preferences > Calendar Options > Office.com Sharing Service

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\outlook\options\pubcal

Description

By default, Outlook does not publish calendars to Office.com more often then the publish interval set by Office.com. This setting allows users to publish calendars more often than the Office.com interval specifies.
