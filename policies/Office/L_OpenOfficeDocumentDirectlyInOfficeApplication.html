Open Office document directly in Office application

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Tools | Options | General | Web Options... > Files

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\common\internet

Description

This policy setting allows you to choose whether Office documents located on web servers open directly in the registered application or through the web browser. If you enable this policy setting, files will open directly in the associated Office application, bypassing the web browser. If you disable this policy setting files will open through the web browser.
