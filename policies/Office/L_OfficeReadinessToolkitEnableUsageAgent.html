Allow add-in usage data to be generated and collected by the Readiness Toolkit

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Readiness Toolkit

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\readinesstoolkit

Description

This policy setting allows you to configure whether the Readiness Toolkit for Office generates and collects add-in usage data. The data generated and collected includes when the add-in is loaded and used, and if the add-in crashes. This information is available in reports provided by the Readiness Toolkit. If you enable this policy setting, the Readiness Toolkit generates and collects add-in usage data. If you disable or don't configure this policy setting, the Readiness Toolkit doesn't generate or collect add-in usage data.
