Show dimmed tagged notes in the Tags Summary task pane

Category

User Configuration > Administrative Templates > Microsoft OneNote 2016 > OneNote Options > Note Flags

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\onenote\options\other

Description

Checks/unchecks the option "Show dimmed tagged notes in the Tags Summary task pane."
