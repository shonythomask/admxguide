Turn off IRM protection on XPS Export for Word

Category

User Configuration > Administrative Templates > Microsoft Word 2016 > Word Options > Security

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\security

Description

This policy controls the default IRM protection setting when exporting Word documents to XPS files. Enabling this policy setting will turn off IRM protection when exporting to XPS, if not explicitly set by users through the Export Options dialog. If you disable or don't configure this policy setting, the default IRM protection setting for XPS export is based on previous IRM export selection.
