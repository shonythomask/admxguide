Maximum number of days to scan from today to determine the user's colleagues for recommendation

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Server Settings > SharePoint Server

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\common\portal\colleagueimport

Description

The maximum number of days to scan the Outlook mailbox to determine the colleagues the user has. The larger the number, the more accurate the recommendation. The smaller the number, the faster the recommendations are generated.
