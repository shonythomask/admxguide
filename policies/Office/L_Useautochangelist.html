Use auto-change list

Category

User Configuration > Administrative Templates > Microsoft Office 2016 > Tools | Options | Spelling

Scope

User

Registry Key

HKCU\software\policies\microsoft\office\16.0\word\options\vpref

Description

Checks/Unchecks the option "Search misused word list". This option is available only if you are using the Korean language version of Microsoft Office or have installed Microsoft Office 2016 proofing tools or the Microsoft Office Single Language Pack 2016 for Korean, and have enabled support for Korean through Microsoft Office 2016 Language Preferences.
