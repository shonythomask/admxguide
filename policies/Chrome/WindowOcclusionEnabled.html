Enable Window Occlusion

Category

Computer Configuration > Administrative Templates > Google Chrome

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

Enables window occlusion in Google Chrome. If you enable this setting, to reduce CPU and power consumption Google Chrome will detect when a window is covered by other windows, and will suspend work painting pixels. If you disable this setting Google Chrome will not detect when a window is covered by other windows. If this policy is left not set, occlusion detection will be enabled.
