Configure native messaging allowlist

Category

Computer Configuration > Administrative Templates > Google Chrome > Native Messaging

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

Setting the policy specifies which native messaging hosts aren't subject to the deny list. A deny list value of * means all native messaging hosts are denied, unless they're explicitly allowed. All native messaging hosts are allowed by default. But, if all native messaging hosts are denied by policy, the admin can use the allow list to change that policy. Example value: com.native.messaging.host.name1 com.native.messaging.host.name2
