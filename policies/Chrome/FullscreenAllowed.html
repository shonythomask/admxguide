ADMX Guide

Allow fullscreen mode

Category

Computer Configuration > Administrative Templates > Google Chrome

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

Setting the policy to True or leaving it unset means that, with appropriate permissions, users, apps, and extensions can enter Fullscreen mode (in which only web content appears). Setting the policy to False means users, apps, and extensions can't enter Fullscreen mode.
