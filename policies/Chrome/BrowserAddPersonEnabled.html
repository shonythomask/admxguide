ADMX Guide

Enable add person in user manager

Category

Computer Configuration > Administrative Templates > Google Chrome

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

If this policy is set to true or not configured, Google Chrome and Lacros will allow to add a new person from the user manager. If this policy is set to false, Google Chrome and Lacros will not allow adding a new person from the user manager.
