Enable the use of relay servers by the remote access host

Category

Computer Configuration > Administrative Templates > Google Chrome > Remote access

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

If RemoteAccessHostFirewallTraversal is set to Enabled, setting RemoteAccessHostAllowRelayedConnection to Enabled or leaving it unset allows the use of remote clients to use relay servers to connect to this machine when a direct connection is not available, for example, because of firewall restrictions. Setting the policy to Disabled doesn't turn remote access off, but only allows connections from the same network (not NAT traversal or relay).
