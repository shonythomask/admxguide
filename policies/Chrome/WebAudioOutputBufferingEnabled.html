Enable adaptive buffering for Web Audio

Category

Computer Configuration > Administrative Templates > Google Chrome

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

This policy controls whether the browser uses adaptive buffering for Web Audio, which may decrease audio glitches but may increase latency by a variable amount. Setting the policy to Enabled will always use adaptive buffering. Setting the policy to Disabled or not set will allow the browser feature launch process to decide if adaptive buffering is used.
