Path to Chrome for switching from the alternative browser.

Category

Computer Configuration > Administrative Templates > Google Chrome > Legacy Browser Support

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

This policy controls the command to use to open URLs in Google Chrome when switching from Internet Explorer®. This policy can be set to an executable file path or ${chrome} to autodetect the location of Google Chrome. Leaving the policy unset means Internet Explorer® autodetects Google Chrome's own executable path when launching Google Chrome from Internet Explorer. Note: If the Legacy Browser Support add-in for Internet Explorer® isn't installed, this policy has no effect. Example value: ${chrome}
