Hide the web store from the New Tab Page and app launcher

Category

Computer Configuration > Administrative Templates > Google Chrome

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

Hide the Chrome Web Store app and footer link from the New Tab Page and Google ChromeOS app launcher. When this policy is set to true, the icons are hidden. When this policy is set to false or is not configured, the icons are visible.
