Allow remote users to interact with elevated windows in remote assistance sessions

Category

Computer Configuration > Administrative Templates > Google Chrome > Remote access

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

Setting the policy to Enabled means the remote assistance host runs in a process with uiAccess permissions. This lets remote users interact with elevated windows on the local user's desktop. Setting the policy to Disabled or leaving it unset means the remote assistance host runs in the user's context, and remote users can't interact with elevated windows on the desktop.
