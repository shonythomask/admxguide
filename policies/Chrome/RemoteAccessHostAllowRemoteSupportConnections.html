ADMX Guide

Allow remote support connections to this machine

Category

Computer Configuration > Administrative Templates > Google Chrome > Remote access

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

If this policy is disabled, the remote support host cannot be started or configured to accept incoming connections. This policy does not affect remote access scenarios. This policy does not prevent enterprise admins from connecting to managed Google ChromeOS devices. This policy has no effect if enabled, left empty, or is not set.
