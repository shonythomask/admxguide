Use Internet Explorer's SiteList policy for Legacy Browser Support.

Category

Computer Configuration > Administrative Templates > Google Chrome > Legacy Browser Support

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

This policy controls whether to load rules from Internet Explorer®'s SiteList policy. When this policy is set to true, Google Chrome reads Internet Explorer®'s SiteList to obtain the site list's URL. Google Chrome then downloads the site list from that URL, and applies the rules as if they had been configured with the BrowserSwitcherUrlList policy. When this policy is false or unset, Google Chrome does not use Internet Explorer®'s SiteList policy as a source of rules for switching browsers. For more information on Internet Explorer's SiteList policy: https://docs.microsoft.com/internet-explorer/ie11-deploy-guide/what-is-enterprise-mode
