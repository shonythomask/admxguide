ADMX Guide

Blocks external extensions from being installed

Category

Computer Configuration > Administrative Templates > Google Chrome > Extensions

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

Controls external extensions installation. Setting this policy to Enabled blocks external extensions from being installed. Setting this policy to Disabled or leaving it unset allows external extensions to be installed. External extensions and their installation are documented at https://developer.chrome.com/docs/extensions/how-to/distribute/install-extensions.
