Enable PDF Annotations

Category

Computer Configuration > Administrative Templates > Google Chrome

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

Controls if the PDF viewer in Google Chrome can annotate PDFs. When this policy is not set, or is set to true, then the PDF viewer will be able to annotate PDFs. When this policy is set to false, then the PDF viewer will not be able to annotate PDFs.
