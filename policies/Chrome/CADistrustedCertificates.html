TLS certificates that should be distrusted by Google Chrome for server authentication

Category

Computer Configuration > Administrative Templates > Google Chrome > Certificate management settings

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

A list of certificate public keys that should be distrusted by Google Chrome for TLS server authentication. The policy value is a list of base64-encoded X.509 certificates. Any certificate with a matching SPKI (SubjectPublicKeyInfo) will be distrusted.
