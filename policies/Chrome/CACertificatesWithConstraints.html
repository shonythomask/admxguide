TLS certificates that should be trusted by Google Chrome for server authentication with constraints

Category

Computer Configuration > Administrative Templates > Google Chrome > Certificate management settings

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

A list of TLS certificates that should be trusted by Google Chrome for server authentication, with constraints added outside the certificate. If no constraint of a certain type is present, then any name of that type is allowed. Certificates should be base64-encoded. At least one constraint must be specified for each certificate. See https://cloud.google.com/docs/chrome-enterprise/policies/?policy=CACertificatesWithConstraints for more information about schema and formatting.
