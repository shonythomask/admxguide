Print Headers and Footers

Category

Computer Configuration > Administrative Templates > Google Chrome > Printing

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

Setting the policy to Enabled turns headers and footers on in print preview. Setting the policy to Disabled turns them off in print preview. If you set the policy, users can't change it. If unset, users decides whether headers and footers appear.
