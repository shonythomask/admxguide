ADMX Guide

Configure extension installation blocklist

Category

Computer Configuration > Administrative Templates > Google Chrome > Extensions

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

Allows you to specify which extensions the users can NOT install. Extensions already installed will be disabled if blocked, without a way for the user to enable them. Once an extension disabled due to the blocklist is removed from it, it will automatically get re-enabled. A blocklist value of '*' means all extensions are blocked by default. Extensions that are explicitly listed in the allowlist are allowed if they are signed (packed). All unpacked extensions are blocked. If this policy is left not set the user can install any extension in Google Chrome. Example value: extension_id1 extension_id2
