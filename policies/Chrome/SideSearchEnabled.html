ADMX Guide

Allow showing the most recent default search engine results page in a Browser side panel

Category

Computer Configuration > Administrative Templates > Google Chrome

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

Setting the policy to Enabled or leaving the policy unset means that users can bring up their most recent default search engine results page in a side panel via toggling an icon in the toolbar. Setting the policy to Disabled removes the icon from the toolbar that opens the side panel with the default search engine results page.
