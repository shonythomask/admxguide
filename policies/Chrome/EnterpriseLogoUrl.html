ADMX Guide

Enterprise Logo URL for a managed profile

Category

Computer Configuration > Administrative Templates > Google Chrome

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

A URL to an image that will be used as an enterprise badge for a managed profile. The URL must point to an image. This policy can only be set as a user policy. It is recommended to use the favicon (example https://www.google.com/favicon.ico) or an icon no smaller than 48 x 48 px. Example value: https://example.com/image.png
