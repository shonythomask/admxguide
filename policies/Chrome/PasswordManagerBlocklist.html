Configure the list of domains for which the Password Manager (Save and Fill) will be disabled

Category

Computer Configuration > Administrative Templates > Google Chrome > Password manager

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

Configure the list of domains where Google Chrome should disable the Password Manager. This means that Save and Fill workflows will be disabled, ensuring that passwords for those websites can't be saved or auto filled into web forms. If a domain is present in the list, the Password Manager will be disabled for it. If a domain is not present in the list, the Password Manager will be available for it. If the policy is unset, the Password Manager will be available for all domains. Example value: example.com login.example.com
