ADMX Guide

Allow Window and Tab capture by these origins

Category

Computer Configuration > Administrative Templates > Google Chrome > Allow or deny screen capture

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

Setting the policy lets you set a list of URL patterns that can use Window and Tab Capture. Leaving the policy unset means that sites will not be considered for an override at this level of Capture. This policy is not considered if a site matches a URL pattern in any of the following policies: TabCaptureAllowedByOrigins, SameOriginTabCaptureAllowedByOrigins. If a site matches a URL pattern in this policy, the following policies will not be considered: ScreenCaptureAllowedByOrigins, ScreenCaptureAllowed. For detailed information on valid url patterns, please see https://cloud.google.com/docs/chrome-enterprise/policies/url-patterns. This policy only matches based on origin, so any path in the URL pattern is ignored. Example value: https://www.example.com [*.]example.edu
