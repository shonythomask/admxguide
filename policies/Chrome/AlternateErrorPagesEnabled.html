ADMX Guide

Enable alternate error pages

Category

Computer Configuration > Administrative Templates > Google Chrome

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

Setting the policy to True means Google Chrome uses alternate error pages built into (such as "page not found"). Setting the policy to False means Google Chrome never uses alternate error pages. If you set the policy, users can't change it. If not set, the policy is on, but users can change this setting.
