Show the middle slot announcement on the New Tab Page

Category

Computer Configuration > Administrative Templates > Google Chrome

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

This policy controls the visibility of the middle slot announcement on the New Tab Page. If the policy is set to Enabled, the New Tab Page will show the middle slot announcement if it is available. If the policy is set to Disabled, the New Tab Page will not show the middle slot announcement even if it is available.
