ADMX Guide

Allow remote access connections to this machine

Category

Computer Configuration > Administrative Templates > Google Chrome > Remote access

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

If this policy is Disabled, the remote access host service cannot be started or configured to accept incoming connections. This policy does not affect remote support scenarios. This policy has no effect if it is set to Enabled, left empty, or is not set.
