Change Memory Saver Mode Savings

Category

Computer Configuration > Administrative Templates > Google Chrome

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

This policy changes the savings level of Memory Saver. This only takes effect when Memory Saver is enabled through settings or through the HighEfficiencyModeEnabled policy, and will affect how heuristics are used to determine when to discard tabs. For example, reducing the lifetime of an inactive tab before discarding it can save memory, but it also means that tabs will be reloaded more frequently which can lead to bad user experience and cost more network traffic. Setting the policy to 0 - Memory Saver will get moderate memory savings. Tabs become inactive after a longer period of time Setting the policy to 1 - Memory Saver will get balanced memory savings. Tabs become inactive after an optimal period of time. Setting the policy to 2 - Memory Saver will get maximum memory savings. Tabs become inactive after a shorter period of time. If this policy is unset, the end user can control this setting in chrome://settings/performance.
