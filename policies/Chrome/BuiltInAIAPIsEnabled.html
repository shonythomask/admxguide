Allow pages to use the built-in AI APIs.

Category

Computer Configuration > Administrative Templates > Google Chrome

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

This policy controls if a page can use the built-in AI APIs (such as LanguageModel API, Summarization API, Writer API, and Rewriter API). If the policy is enabled or unset, the APIs are enabled to be used. If the policy is disabled, attempting using the APIs will result in an error.
