ADMX Guide

Enable dismissing compromised password alerts for entered credentials

Category

Computer Configuration > Administrative Templates > Google Chrome > Password manager

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

Setting the policy to Enabled or leaving it unset gives the user the option to dismiss/restore compromised password alerts. If you disable this setting, users will not be able to dismiss alerts about compromised passwords. If enabled, users will be able to dismiss alerts about compromised passwords.
