Command-line parameters for switching from the alternative browser.

Category

Computer Configuration > Administrative Templates > Google Chrome > Legacy Browser Support

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome

Description

Setting the policy to a list of strings means the strings are joined with spaces and passed from Internet Explorer® to Google Chrome as command-line parameters. If a parameter contains ${url}, ${url} is replaced with the URL of the page to open. If no parameter contains ${url}, the URL is appended at the end of the command line. Environment variables are expanded. On Microsoft® Windows®, %ABC% is replaced with the value of the ABC environment variable. Leaving the policy unset means Internet Explorer® only passes the URL to Google Chrome as a command-line parameter. Note: If the Legacy Browser Support add-in for Internet Explorer® isn't installed, this policy has no effect. Example value: --force-dark-mode
