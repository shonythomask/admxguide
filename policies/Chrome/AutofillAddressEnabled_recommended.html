Enable AutoFill for addresses

Category

Computer Configuration > Administrative Templates > Google Chrome - Default Settings (users can override)

Scope

Both

Registry Key

HKLM\Software\Policies\Google\Chrome\Recommended

Description

Setting the policy to True or leaving it unset gives users control of Autofill for addresses in the UI. Setting the policy to False means Autofill never suggests or fills address information, nor does it save additional address information that users submit while browsing the web.
