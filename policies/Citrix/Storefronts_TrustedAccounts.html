Trusted Store Accounts List

Category

Computer Configuration > Administrative Templates > Citrix Components > Citrix Workspace > StoreFront

Scope

Machine

Registry Key

HKLM\Software\Policies\Citrix\Receiver\TrustedAccounts

Description

This policy lets you add a list of trusted store account URLs. Adding a store account to the list prevents the prompt that asks you to trust the store from appearing when you configure the store by using the provisioning file. Here is an example of a Store account URL: https://sales.mycompany.com/Citrix/Store/discovery
