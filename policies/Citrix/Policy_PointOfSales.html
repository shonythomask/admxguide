USB Point of Sale Devices

Category

Computer Configuration > Administrative Templates > Citrix Components > Citrix Workspace > Remoting client devices

Scope

Machine

Registry Key

HKLM\Software\Policies\Citrix\ICA Client\Engine\Lockdown Profiles\All Regions\Lockdown\Virtual Channels\DVC_PlugAndPlay

Description

Use this policy to enable and disable published application or desktop access to the client USB Point of Sale devices. This policy is applied if the USB Plug-n-Play Devices policy is set to Enabled and Not Configured.
