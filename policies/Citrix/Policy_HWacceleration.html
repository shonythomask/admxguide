Hardware Acceleration for graphics

Category

Computer Configuration > Administrative Templates > Citrix Components > Citrix Workspace > User experience

Scope

Machine

Registry Key

HKLM\Software\Policies\Citrix\ICA Client\Graphics Engine

Description

Use this policy to enable or disable the use of hardware acceleration (GPU) for remote graphics. When not configured the use of hardware acceleration is enabled on non-embedded GPUs. When enabled, Citrix Workspace will attempt to use the client GPU to accelerate the remote graphics. On client devices that do not support this feature it is disabled silently.
