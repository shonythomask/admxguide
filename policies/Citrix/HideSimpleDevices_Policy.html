USB Devices List In Desktop Viewer

Category

Computer Configuration > Administrative Templates > Citrix Components > Citrix Workspace > Remoting client devices > Generic USB Remoting

Scope

Machine

Registry Key

HKLM\Software\Policies\Citrix\ICA Client\USB

Description

Choose whether USB devices that can be connected using alternative HDX technologies should appear in USB Devices list. Devices that can be connected using other HDX technologies include simple USB drives, webcams, scanners, printers, and audio devices. This setting overrides the user's preference.
