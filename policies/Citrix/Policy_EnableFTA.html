ADMX Guide

Enable FTA

Category

Computer Configuration > Administrative Templates > Citrix Components > Citrix Workspace > SelfService

Scope

Machine

Registry Key

HKLM\SOFTWARE\Policies\Citrix\Dazzle

Description

Use this option to change the FTA (File Type Association) settings. By default, this policy is set to Not Configured. Select Enabled to enable FTA. Select Disabled to disable FTA.
