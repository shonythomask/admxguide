ADMX Guide

Cache

Category

Computer Configuration > Administrative Templates > Citrix Components > Citrix Workspace > Citrix Secure Browser

Scope

Machine

Registry Key

HKLM\Software\Policies\Citrix\Secure Browser\

Description

Use this policy to enable/disable browser cache. By default caching is enabled. When Enabled browser cookies and resources are cached on local disk. When Disabled browser cookies and resources are not stored.
