USB Plug-n-Play Devices

Category

User Configuration > Administrative Templates > Citrix Components > Citrix Workspace > Remoting client devices

Scope

User

Registry Key

HKCU\Software\Policies\Citrix\ICA Client\Engine\Lockdown Profiles\All Regions\Lockdown\Virtual Channels\DVC_PlugAndPlay

Description

Use this policy to enable and disable published application or desktop access to the client USB Plug-n-Play devices. The Not Configured setting allows device access until you explicitly enable or disable access.
