Keyboard shortcuts

Category

Computer Configuration > Administrative Templates > Citrix Components > Citrix Workspace > User experience

Scope

Machine

Registry Key

HKLM\Software\Policies\Citrix\ICA Client\Engine\Lockdown Profiles\All Regions\Lockdown\Client Engine\Hot Keys

Description

This option enables configuring key combinations that the Citrix Workspace can use. From the Windows Key drop down menu, select the preferred option. The available options are Access Local Desktop, Access Remote Session and Access Remote session in full screen only. When Access Local Desktop is selected, the key combination is applicable only to the local desktop. When Access Remote Session is selected, the key combination is applicable only to the remote session. When Access Remote session in full screen only is selected, the key combination is applicable to non-seamless ICA sessions in full screen mode. By default, this option is selected.
