Citrix Workspace Updates

Category

Computer Configuration > Administrative Templates > Citrix Components > Citrix Workspace > Citrix Workspace Updates

Scope

Machine

Registry Key

HKLM\Software\Policies\Citrix\ICA Client\AutoUpdate

Description

Not Configured – Citrix Workspace Updates is enabled. Enabled – Citrix Workspace Updates is enabled with the additional options listed in this dialog. Disabled – Citrix Workspace Updates option is hidden from the Advanced Preferences sheet and you will not receive any update notifications. Enable Citrix Workspace Update Policy: Auto = Citrix Workspace checks for updates automatically. Manual = User checks for updates manually. LTSR ONLY: True = Only LTSR updates will be available. Migrate 32-bit application to system processor architecture (64-bit or ARM64): When checked, the auto-updates upgrade Citrix Workspace from 32-bit to match the system processor architecture (64-bit or ARM64). By default, updates keep the current architecture.
