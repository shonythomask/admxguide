Single Sign-on for NetScaler Gateway

Category

Computer Configuration > Administrative Templates > Citrix Components > Citrix Workspace > User authentication

Scope

Machine

Registry Key

HKLM\Software\Policies\Citrix\ICA Client\Engine\Lockdown Profiles\All Regions\Lockdown\Logon\NSGSSON

Description

Use this policy to allow the Workspace to use the same log on credentials (pass-through authentication) on NetScaler Gateway.
