ADMX Guide

Managed Bookmarks (JSON on one line)

Category

Computer Configuration > Administrative Templates > Firefox

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox

Description

If this policy is enabled, you can use JSON to configure managed bookmarks. If this policy is disabled or not configured, managed bookmarks are not added. For detailed information on creating the policy, see https://github.com/mozilla/policy-templates/blob/master/README.md#managedbookmarks.
