ADMX Guide

Tracking Protection Mode

Category

Computer Configuration > Administrative Templates > Firefox > Tracking Protection

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\EnableTrackingProtection

Description

If this policy is enabled, the tracking protection mode can be set to either Standard or Strict, and the user cannot change it. If this policy is disabled or not configured, the default tracking protection mode is used and the user can change it.
