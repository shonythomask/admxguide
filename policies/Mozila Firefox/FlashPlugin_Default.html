ADMX Guide

Activate Flash on websites

Category

Computer Configuration > Administrative Templates > Firefox > Flash

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\FlashPlugin

Description

If this policy is enabled, Flash is always activated on websites. If this policy is disabled, Flash is never activated on websites, even if they are in the specified in the Allow list. If this policy is not configured, Flash is click to play.
