ADMX Guide

browser.cache.disk.enable

Category

Computer Configuration > Administrative Templates > Firefox > Preferences (Deprecated)

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\Preferences

Description

If this policy is enabled, the preference is locked to true. If this policy is disabled, the preference is locked to false. For a description of the preference, see: https://github.com/mozilla/policy-templates/blob/master/README.md#preferences
