Deny Url Regex List

Category

Computer Configuration > Administrative Templates > Firefox > Content Analysis (DLP)

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\ContentAnalysis

Description

If this policy is enabled, you can specify a space-separated list of regular expressions that indicates URLs for which DLP operations will always be denied without consulting the agent. If this policy is disabled or not configured, the DLP agent will always be consulted.
