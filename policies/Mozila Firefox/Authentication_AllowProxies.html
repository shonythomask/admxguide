ADMX Guide

Allow Proxies

Category

Computer Configuration > Administrative Templates > Firefox > Authentication

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\Authentication\AllowProxies

Description

If this policy is disabled, SPNEGO and NTLM will not authenticate with proxy servers. If this policy is enabled (and the checkboxes are checked) or not configured, NTLM and SPNEGO will always authenticate with proxies.
