ADMX Guide

TLS_RSA_WITH_AES_128_GCM_SHA256

Category

Computer Configuration > Administrative Templates > Firefox > Disabled Ciphers

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\DisabledCiphers

Description

If this policy is enabled, the corresponding cipher is disabled. If this policy is disabled, the corresponding cipher is enabled. If this policy is not configured, the corresponding cipher is enabled or disabled based on the default in Firefox.
