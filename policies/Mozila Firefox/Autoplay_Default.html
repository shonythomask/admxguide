ADMX Guide

Default autoplay level

Category

Computer Configuration > Administrative Templates > Firefox > Permissions > Autoplay

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\Permissions\Autoplay

Description

If this policy is enabled, you can choose the default autoplay level. If this policy is disabled or not configured, audio is blocked by default. Note: Blocking audio and video does not work on the ESR.
