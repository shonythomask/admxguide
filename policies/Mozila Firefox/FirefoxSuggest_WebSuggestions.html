ADMX Guide

Suggestions from the web

Category

Computer Configuration > Administrative Templates > Firefox > Firefox Suggest (US only)

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\FirefoxSuggest

Description

If this policy is enabled, you will get suggestions from Firefox related to your search. If this policy is disabled, you will not get these suggestions. If this policy is not configured, you will get suggestions from Firefox related to your search.
