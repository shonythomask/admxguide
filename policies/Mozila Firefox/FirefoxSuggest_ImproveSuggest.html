ADMX Guide

Improve the Firefox Suggest experience

Category

Computer Configuration > Administrative Templates > Firefox > Firefox Suggest (US only)

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\FirefoxSuggest

Description

If this policy is enabled, you will help create a richer search experience by allowing Mozilla to process your search queries. If this policy is disabled or not configured, you do not allow Mozilla to process your search queries.
