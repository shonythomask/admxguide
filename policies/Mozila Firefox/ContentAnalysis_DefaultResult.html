ADMX Guide

Default Result

Category

Computer Configuration > Administrative Templates > Firefox > Content Analysis (DLP)

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\ContentAnalysis

Description

If this policy is enabled, you can indicate the desired behavior for DLP requests if there is a problem connecting to the DLP agent. If this policy is disabled or not configured, the DLP request will be denied if there is a problem connecting to the agent.
