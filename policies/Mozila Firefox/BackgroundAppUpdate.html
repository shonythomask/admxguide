ADMX Guide

Background updater

Category

Computer Configuration > Administrative Templates > Firefox

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox

Description

If this policy is disabled, the application will not try to install updates when the application is not running. If this policy is enabled or not configured, application updates may be installed (without user approval) in the background, even when the application is not running. The operating system might still require approval.
