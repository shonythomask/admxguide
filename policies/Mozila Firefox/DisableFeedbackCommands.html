ADMX Guide

Disable Feedback Commands

Category

Computer Configuration > Administrative Templates > Firefox

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox

Description

If this policy is enabled, the "Submit Feedback" and "Report Deceptive Site" menu items are not available from the help menu. If this policy is disabled or not configured, the "Submit Feedback" and "Report Deceptive Site" menu items are available from the help menu.
