ADMX Guide

Enabled

Category

Computer Configuration > Administrative Templates > Firefox > Tracking Protection

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\EnableTrackingProtection

Description

If this policy is enabled, tracking protection is enabled. If this policy is disabled, tracking protection is disabled and cannot be changed by the user. If this policy is not configured, standard tracking protection is used and the user can change it.
