Override the first run page

Category

Computer Configuration > Administrative Templates > Firefox

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox

Description

If this policy is enabled, you can specify a URL to be used as the first run page. If you leave the URL blank, no first run page will be shown. Starting with Firefox 83, Firefox ESR 78.5, you can also specify multiple URLS separated by a vertical bar (|). If this policy is disabled or not configured, the first run page is displayed.
