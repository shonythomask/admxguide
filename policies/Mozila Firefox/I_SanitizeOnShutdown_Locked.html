ADMX Guide

Locked

Category

Computer Configuration > Administrative Templates > Firefox > Clear data when browser is closed

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\SanitizeOnShutdown

Description

If this policy is disabled, all shutdown preferences can be changed by the user. If this policy is enabled, any shutdown preferences explicitly set via policy cannot be changed by the user. If this policy is not configured, no shutdown preferences can be changed by the user (previous behavior).
