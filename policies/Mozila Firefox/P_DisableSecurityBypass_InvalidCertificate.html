ADMX Guide

Prevent overriding certificate errors

Category

Computer Configuration > Administrative Templates > Firefox

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\DisableSecurityBypass

Description

If this policy is enabled, the "Add Exception" button is not available when a certificate is invalid. This prevents the user from overriding the certificate error. If this policy is disabled or not configured, certificate errors can be overridden.
