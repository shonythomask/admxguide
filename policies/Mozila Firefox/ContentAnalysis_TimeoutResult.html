ADMX Guide

Timeout Result

Category

Computer Configuration > Administrative Templates > Firefox > Content Analysis (DLP)

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\ContentAnalysis

Description

If this policy is enabled, you can indicate the desired behavior for DLP requests if the DLP agent does not respond to a request in less than AgentTimeout seconds. If this policy is disabled or not configured, the request will be denied.
