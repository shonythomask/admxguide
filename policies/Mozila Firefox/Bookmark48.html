ADMX Guide

Bookmark 48

Category

Computer Configuration > Administrative Templates > Firefox > Bookmarks

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\Bookmarks\7

Description

If this policy is enabled, you can configure a bookmark to be added to Firefox. Due to a bug, you must select the location. Note that you must specify the bookmarks in order. If this policy is disabled or not configured, a new bookmark is not added.
