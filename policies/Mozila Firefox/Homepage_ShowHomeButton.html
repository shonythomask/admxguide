ADMX Guide

Show Home button on toolbar

Category

Computer Configuration > Administrative Templates > Firefox > Home page

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox

Description

If this policy is enabled, the home button will appear on the toolbar by default. If this policy is disabled, the home button will not appear on the toolbar by default. If this policy is not configured, Firefox will determine whether or not the home button appears on the toolbar by default.
