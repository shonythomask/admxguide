ADMX Guide

Enable Encrypted Media Extensions

Category

Computer Configuration > Administrative Templates > Firefox > Encrypted Media Extensions

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\EncryptedMediaExtensions

Description

If this policy is disabled, encrypted media extensions (like Widevine) are not downloaded by Firefox unless the user consents to installing them. If this policy is enabled or not configured, encrypted media extensions (like Widevine) are downloaded automatically and used by Firefox.
