ADMX Guide

Fallback

Category

Computer Configuration > Administrative Templates > Firefox > DNS Over HTTPS

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\DNSOverHTTPS

Description

If this policy is disabled, Firefox will not fallback to your default DNS resolver if there is a problem with the secure DNS provider. If this policy is enabled or not configured, Firefox will use your default DNS resolver if there is a problem with the secure DNS provider.
