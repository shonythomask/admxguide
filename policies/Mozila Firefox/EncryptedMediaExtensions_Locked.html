ADMX Guide

Lock Encrypted Media Extensions

Category

Computer Configuration > Administrative Templates > Firefox > Encrypted Media Extensions

Scope

Both

Registry Key

HKLM\Software\Policies\Mozilla\Firefox\EncryptedMediaExtensions

Description

If this policy is enabled and EncryptedMediaExtensions are disabled, Firefox will not download encrypted media extensions (like Widevine) or ask the user to install them. If this policy is disabled or not configured, it has no effect.
